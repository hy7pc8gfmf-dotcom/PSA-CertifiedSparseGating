## 4. 本轮更新【新引入】的问题（回归点）

### 4.1 复合证书被误读为 "0.135 的紧证书" —— 旧错被有效但空洞的定理"背书"
论文新主张（B 正式 L218："复合证书即其紧证书"；A 中文 L39/L131："核-边缘分解交付的部分证书在此收束为七带整体完整证书… 其精确相干行和仅 0.135 ≤ 4/5，实质可认证"）。

**最强推理核验**（基于 `PSA_framework.v:4906-5085` 的精确核算）：
- `delta_e5` 表 21 项双方向和（对称，每对计两次）。单位系数下 `Σ_{i<j} δ_e5 ≈ 7.1065` ⇒ `coh_e5 = 2 × 7.1065 = 14.21`。
- 证书给出 `(S − coh_e5) ≤ ‖F‖² ≤ (S + coh_e5)` = **[7 − 14.21, 7 + 14.21] = [−7.21, 21.21]**。
- 该证书的"相干聚合量" `coh_e5 / S = 2.03`，与论文宣称的 **0.135 完全不相交**——复合证书的数学对象与 "0.135 相干行和" 是**两个无关量**。
- 逻辑自洽性矛盾（论文自毁）：论文既称"反射检查器判 E5'' 为 **false**"，又称"其精确行和仅 0.135 ≤ 4/5"。若真行和=0.135≤4/5，检查器必返回 **true**。返回 false 当且仅当真行和 > 4/5。故"false + 0.135"在论文自身陈述内**不可能同时成立**。前轮暴力核验（1.2287）与检查器返回 false 一致，证实 0.135 为假。

**结论**：复合证书 `champion_e5_composite_certificate` 本身是**合法 Qed 定理**，但其下界空洞（−7.21）、上界 (21.21) 比 Gershgorin 还松，**既非紧、也未建立 E5'' 为有效框架**。论文将其标为 E5'' 的"紧证书"并用作 "0.135 实质可认证" 的论据，属于**对新定理的过度解读 + 对旧错误的持续背书**——这是本轮引入的**回归**：错误未消，反被一个被正确证明但被错误引用的定理所加固。

### 4.2 反射层修复无法独立验证（工件缺口的连带后果）
§2 中"反射层 bug 已修复"由论文自述，但 `PSA_extract.v` 不在快照，无法读 `row_sum_frac_aux`/`orig` 参数核验。这与 A-3/B-6 工件缺失同源——**可信度依赖作者申报，审稿人不可复现**。
