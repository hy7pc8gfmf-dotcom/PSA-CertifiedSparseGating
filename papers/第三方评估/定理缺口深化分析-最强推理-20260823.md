## 1. 第一优先（核心架构 / 直接强化两篇论文）

### G-1　加权阶梯范数精确闭式 ★（评估 T\*-2 定理化）
- **陈述**：对混窗阶梯 `F = Σ_i c_i·ψ_{n_i}`，`‖F‖²_W = Σ_i |c_i|²·‖ψ_{n_i}‖²_W + 2·Σ_{i<j} c_i·c_j·K_W(n_i,n_j)`，其中 `K_W` 为**显式 Dirichlet 核比闭式**（单对公式 `probe_pairbound.v:4` 的窗口求和版）。
- **资产**：`geom_sum_identity`（probe_partial）、`pair_inner_norm`（PB4，ρ^{−3/2} 上界）、`norm_sq_comboM_rec`（PSA_framework）、`geom_sum_norm_dirichlet`（未归一化）。
- **路线**：单对闭式按窗口混叠求和 → 交叉项 K_W 的显式三角和 → 归纳组装。
- **杠杆**：根治 A-1/B-1（12.5× 口径混用——因为有了等式就不需要两套近似）；是 G-2/G-3/G-4 的前置。
- **难度**：高（复分析求和），但零件全在。

### G-2　相邻带相干渐近闭式 + 相变定理 ★（评估 T\*-3 + 交叉核验 μ_adj 定理化）
- **陈述**：比率 r 阶梯 `n_{k+1} ≥ r·n_k` 的相邻带相干（口径①）满足 `lim_{k→∞} μ(n_k, n_{k+1}) = μ_adj(r) := √r·sin(π/r)/(π(r−1))`，且存在**相变点 r\***（μ_adj(r\*)=4/5，数值 ≈1.30）：r ≥ r\* ⟹ 渐进可认证；r→1⁺ ⟹ μ_adj→1 不可认证。
- **资产**：`sin_lower`（Jordan）、`pair_S_bound`（PB3）、`Cnorm_one_minus_exp_i_theta_eq`、`ca_fourier`/`ca_taylor` 渐近工具。
- **路线**：G-1 的 K_W 对相邻带取极限 → Jordan 夹逼 → μ_adj 单调性（R 层 nra）+ 相变点数值（有理化 √ 界）。
- **杠杆**：把"E5 一个数据点"升级为**完整相图**；直接落实 B-7 的强叙事。
- **难度**：中高（G-1 依赖）。

### G-3　可认证性充要刻画（评估 T\*-1）
- **陈述**：阶梯族经有理反射检查器以常数 μ\* 可认证 ⟺ sup 相干上确界 ≤ μ\*（必要方向的构造性反例 + 紧性）。
- **前置**：G-1/G-2（把上确界写成闭式）。
- **难度**：高（必要方向需构造反例）。

### G-4　倍增阶梯不可认证下界（评估 T\*-4 具体化）★
- **陈述**：r=2 倍增阶梯任意 ≥4 带（或起点 ≥[7,15,31] 的 3 带）整梯不满足 `(1−μ)S ≤ ‖F‖²`（μ≤4/5 口径），**带显式常数**：内部带两邻相干和 → 2·0.4502 = 0.9003 > 4/5（交叉核验 §3 的定理化）。
- **资产**：`no_nine_band_ladder`（packing 不可能性技术）、G-2 的 μ_adj(2)。
- **杠杆**：把"整梯不可认证"从注释（PSA_framework.v:3420）升级为**紧负结果定理**；与 G-3/G-2 构成"子族可证 / 整梯不可证 / 边界在此"三角。
- **难度**：中（packing 技术现成）。

### G-5　可判定性溢价定理 ★（替换 49.1% 假阴性叙事）
- **陈述**：[3,7,15] 精确最大行和 0.7870 ≤ 4/5（可认证）但有理反射界 1.3125 > 4/5（被拒）⟹ **可判定性溢价 ≥ 1.3125/0.7870 ≈ 1.67**：存在精确可证但有理保守判为拒绝的实例。
- **资产**：`frame_check_instance`（反射器）、精确行和重算脚本（交叉核验 §5）、`row_sum_3halfs`。
- **杠杆**：替换可疑的 49.1%（口径混用产物，审稿 A-7/B-4）——"可判定性溢价"是可验证的真例证，且是检查器完备性 gap 的**量化下界**。
- **难度**：低-中（重算已是脚本，定理化需精确行和闭式——G-1 子件）。

### G-6　E5 族极大性（评估 T\*-5）
- **陈述**：[3,511] 内、相邻比 ≥ c_pareto 的阶梯族中，E5=[3,13,53,213] 在"可认证前提"下最大化族规模/最小化 μ。
