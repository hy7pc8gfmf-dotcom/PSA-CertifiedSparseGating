## A. 形式化侧（Coq，PSA_framework.v 追加）

### A1 [最高优先] softmax 敏感性引理（文档 ②，解锁 T3）
- 目标：`‖softmax(z) − softmax(z′)‖₁ ≤ 2·‖z − z′‖_∞`（差分隐私标准事实）
- 意义：把"softmax 不在覆盖内"从**身份缺口**转为**敏感性有界**——T3 认证低秩的最后一环：
  丢弃谱能量 ≤ ε → 核扰动 ≤ f(ε) →（本引理）输出分布扰动 ≤ 2f(ε)
- 实现：Reals 层有限维 softmax（fun i => exp(z_i)/Σexp）；1-范数与 ∞-范数；已知证明骨架
- 验收：编译 RC=0、零 classic（预期 sig_forall_dec+fext 继承）
- 前置：无（独立）；工作量：中

### A2 Gershgorin 实例证书（文档 ①，先数值侦察）
- 第一步（数值侦察，30 分钟）：对实际 m=128 梯子（C=4）算有限 Gram 的**最小特征值**
  ——若 λ_min 显著 > 0，则 C=4 梯子实际非退化，C>25 裂缝是"最坏情形界"的保守而非事实
- 第二步（若值得形式化）：Gershgorin 圆盘定理的 Coq 形式化（对称阵 λ ≤ max(a_ii+Σ|a_ij|)）
  + 对实际 Gram 实例化 → "实例认证的框架下界"
- 意义：可能**直接消灭 C>25 问题**（T1 子框架从"必需的桥"降级为通用定理）
- 工作量：数值快；形式化中-大（或先用数值报告支撑论文的"实例紧致性"小节）

### A3 T5+ 位置 logit 有界性（文档 ④）
- 目标：位置对任意 logit 的贡献 ≤ ‖P‖·‖W_Q‖·‖W_K‖·c(ladder)，对**一切 T** 一致成立
- 意义：把实测的 psi/dense 比率稳定（0.84-0.90、无 NaN）升格为白盒定理——外推安全锚点
- 实现：矩阵范数次乘性 + psi 特征界（已有 Cnorm_psi）
- 工作量：中

### A4 频率分离泛化（文档 ③，论文数学深度）
- 目标：几何增长 → 任意"频率分离"集（Sidon/B₂[g]）⟹ 相干性界；检查器取代生成器
- 实现：Dirichlet 核界只用 |1/n_i − 1/n_j| 下界——把前提从"几何梯子"放松为"可判定检查通过"
- 工作量：大（调和分析深度），建议置于 A1/A2 之后

### A5 psi-rope 核族条件数（文档 ④，与 B1 互为地基）
- 目标：相对核族 {cos(2πd/n_j), sin(2πd/n_j)}（d 的函数族）的 Gram/框架界——"RoPE 梯子带证书"
- 工作量：中；建议与 B1 实验同步

## B. 实证侧（psa_empirical/，GPU 可用）

### B1 [最高价值] psi-rope 合成（上一轮修正形态）
- 实现：length_extrap.py 加 `psi-rope` 模式——psi 频率梯子 + 逐频 2×2 旋转块（RoPE 式）
  （约束 psi_proj 为块对角 = 纯旋转，去掉自由混合的绝对相位项）
- 配置：截断梯子（n_j ≤ 512）或不截断 × 块对角投影；对照 dense/psi/psi-trunc/rope
- 预期：外推接近 RoPE（25@4096）且保留 psi 可证明频率梯子——"证明 + 外推"双得
- 验收：外推曲线（512-4096）四模式对比表

### B2 E1 消融（-17% 归因，论文必需）
- 矩阵：{几何梯子 / 线性梯子 / 随机频率} × {自由投影 / 块对角投影} + 控制组
  （dense、wpe 低秩 16、随机冻结 wpe、RoPE）
- 意义：回答"-17% 是位置瓶颈还是梯子几何"——不拆开论文站不住
- 验收：消融矩阵表（训练长度内 ppl）

### B3 E3 C 扫描（甜蜜点/匹配滤波器假说）
- C ∈ {2,4,8,16,26,64}，测：训练长度 ppl + 实测相干 + sparsity
- 意义：验证"可证明甜蜜点 C≥26"（框架界非真空）与"语言尺度匹配滤波器 C≈4-5"的张力
- 验收：ppl/相干/sparsity vs C 曲线

### B4 BPE 级复刻（enwik8，外部效度）
- 意义：char-level 结论能否迁移到 BPE——外部效度最后一块
- 前置：enwik8 数据（社区源）；工作量：中

## 风险与诚实边界
- B1 psi-rope 若外推仍差：说明 psi 频率梯子本身不适合外推（RoPE 的 θ 底数/缩放是关键），
  则"证明 + 外推"主张降级，回到"训练长度内 psi 与 RoPE 同级 + 证书"叙事
- A2 若 λ_min ≈ 0：C=4 梯子实际退化（需子框架抽取救场，T1 升回最高优先）
- B2 若 -17% 主要来自瓶颈：论文改为"位置通道压缩的正则化效应"叙事（仍可发，但卖点改）
