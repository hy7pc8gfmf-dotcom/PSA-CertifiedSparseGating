## 〇、上帝视角：频率阶梯原子族为何是压缩感知的天然载体

频率阶梯原子族（窗口化复指数，`psi n k = (1/√n)·e^{2πik/n}`，有限支撑 k < n）同时具备
**三重结构性质**——这是其他字典（随机、小波、傅里叶子集）难以兼得的：

| 结构性质 | 数学内容 | 代码库现状 |
|---|---|---|
| **(a) 原子规范** | ‖ψ_n‖² = 1（单位范数，可判定） | ✅ `psi_norm_one`（已证） |
| **(b) 低相干 + 解析闭式** | 逐对相干 |⟨ψ_a,ψ_b⟩| = \|sin(πTΔ)/(sin πΔ)\|/√(ab)，Θ(ρ^{−3/2}) 衰减；行和 C=4 < 1 | ✅ `pair_inner_norm`、`row_sum_3halfs`、`row_bound_C4`（已证） |
| **(c) 窗口自适应** | 相干随窗口 T 变化（Dirichlet 核精确可算） | ✅ `dirichlet_partial_bound`、`pair_dirichlet`（已证） |

**上帝视角断言**：(a)+(b)+(c) ⟹ 该原子族应支撑一整套压缩感知理论——**RIP(k,δ) → k-稀疏恢复唯一 → 恢复算法保证 → 不确定性原理 → 最优相干（Welch）**。
但当前代码库**只完成了 2-原子 RIP（rip_bound2）与通用层唯一性（sparse_uniquenessM）**，
k-原子 RIP、数值实例化、Welch 最优性、不确定性原理等**非平凡最终定理全部缺席**——
这正是论文 §9 压缩感知强度不足的根源。

## 二、缺失的非平凡最终定理（焦点 F1–F7）

### F1 ★ 焦点：k-原子 RIP 定理（RIP(k, δ_k)，压缩感知强度的核心缺口）

**数学陈述**（上帝视角应有）：
```
rip_bound_k (u : nat -> nat -> Complex) (W M : nat) (mu : R) :
  ∀j≤M: ‖u_j‖²_W = 1 → ∀i≠j≤M: |⟨u_i,u_j⟩_W| ≤ mu →
  ∀c (k-稀疏, 支撑 ⊆ {0..M}):
    (1 − (k−1)·mu)·Σc_j² ≤ ‖Σ_{j∈S} c_j·u_j‖²_W ≤ (1 + (k−1)·mu)·Σc_j²
```
**数学依据**：Gershgorin 对角占优 / 相干性 RIP。
‖Σc_j u_j‖² = Σc_j² + 2Σ_{i<j} c_i c_j ⟨u_i,u_j⟩，交叉项
\|2Σ_{i<j} c_i c_j⟨u_i,u_j⟩\| ≤ 2μ·Σ_{i<j}|c_i c_j| ≤ μ(k−1)·Σc_j²
（末步：2Σ_{i<j}|c_i c_j| ≤ (k−1)Σc_j²——每项 2|ab| ≤ a²+b² 聚合，**正是 `sum_abs_cross_le` 已证的形态**）。

**已有零件（全部就绪）**：
- `norm_sq_comboM_rec`（M-原子展开——给出 ‖Σc_j u_j‖² 的显式 Σc² + 交叉项形态）
- `cross_abs_le`（\|⟨u_i,u_j⟩\| ≤ mu 的交叉项界）
- `sum_abs_cross_le`（交叉项 AM-GM 聚合 → μ(k−1)Σc²——**这就是 RIP 常数 δ_k=(k−1)μ 的证明核心**）
- `sum_sq_nonneg`、`Rabs_prod_le_sq_sum`（AM-GM 基元）

**缺口**：只有组装——把 `norm_sq_comboM_rec` + `sum_abs_cross_le` + 三角不等式组合成
`rip_bound_k` 主定理。**工作量：1 个探针（probe_rip_k 或并入 probe_incoherence），
数学上 30 分钟，Coq 上 1-2 小时。**

**论文意义**：这是论文 §9 从"2-原子 RIP"升级为"**k-原子 RIP**"的关键定理——
压缩感知的标准保证（Candès–Tao：δ_{2k} < √2−1 ⟹ 基追踪精确恢复）的直接前提。

### F4 焦点：Welch 界与原子族最优性

**数学陈述**：

**依据**：`witness_sandwich` 已证相干上下界比 → 1（Θ(C^{−3/2}) 紧性封顶）——这已接近

**缺口**：Welch 界本身的 Coq 证明（线性代数：Gram 矩阵迹 + Cauchy-Schwarz）+ 与已有

**论文意义**：证明频率阶梯原子族**在低相干意义下接近理论最优**——"无条件基 + 最优相干"

## 五、风险与边界（如实）

- F1 的 δ_k=(k−1)μ 用**保守 μ**（如 4/5）时，k≥2 即 δ≥0.8<1（有界），k 大则退化——
  需要 F2 的精确 μ 才给出大 k 的强 RIP（诚实声明：F1 证明"存在 k-原子 RIP"，其强度依赖 μ 精度）。
- F7 恢复算法形式化是独立的大工程（凸优化/贪心 + 数值），不应低估；建议先形式化
  "唯一性 ⟹ 任意恢复算法输出的正确性"（确定性部分，无算法本体）。
- 频率阶梯原子族的窗口有限支撑（k < n）使"长窗口"相干为 0（长带死重）——这是
  结构优势（解析闭式），也是约束（原子数受限），方案中已利用闭式。
