## 路线 A：softmax 敏感性引理 → 认证低秩注意力（T3 闭合）

### A1. 新模块 SoftmaxStability

**目标引理 S1（弱版，先行垫脚石）**：
```
softmax_l1_bound_weak :
  ||z - z'||_inf <= d -> ||softmax z - softmax z'||_1 <= 2*(exp d - 1)
```
证明路径：softmax 移位不变性 softmax(z+c·1) = softmax(z) + 每分量比率界
|p_i/p'_i − 1| ≤ e^d − 1（e^{z_i}/Σe^{z_j} 与 e^{z'_i}/Σe^{z'_j} 的逐项比较）。

**目标引理 S2（紧版）**：
```
softmax_l1_bound :
  ||z - z'||_inf <= d -> ||softmax z - softmax z'||_1 <= 2*d
```
⚠️ 紧常数（恰好 2d）需要文献核对（DP 领域标准事实，但 Coq 化前确认证明路径）；
**若紧版受阻，弱版（e^d−1 系数）足以支撑 T3 全链**，只是 f(ε) 形状变化——设计上不阻塞。
另备逐分量版 ‖softmax z − softmax z′‖_∞ ≤ ‖z−z′‖_∞（二维手算成立：z=(0,0), z′=(δ,0) 给 δ/4）。

实现要点：list-R 基础设施复用 RowTruncation 的 list_sum_R / fold_right 模式；
exp 的处理走 Coquelicot。预计 2-4 个引理，零 classic（Reals 继承）。

### A2. T3 认证低秩注意力（主线 3 的定理本体）

**分解（全部小件，无新数学）**：
```
T3_chain :
  (每行丢弃谱能量 ≤ ε)                    -- P1b 已证（row_dropped_energy_bound）
  -> (该行 logit 扰动 ||Δz_i||_inf ≤ √ε)   -- ℓ_∞ ≤ ℓ_₂（新，一行级）
  -> (该行注意力分布 ||Δp_i||_1 ≤ 2√ε)     -- S2
  -> (输出 ||Δout_i|| ≤ 2√ε · max||v||)    -- 加权平均的 Lipschitz（新，一行级）
```
输出定理形态：
```
certified_attention_approx :
  dropped_spectral_energy_per_row <= ε -> ||attn_out - attn_out_approx|| <= 2*sqrt ε * V_max
```
**注意**：链条只覆盖"核扰动 → 输出扰动"的传播；谱截断本身（哪些项被丢）由 P1b 的
能量预算控制。两件拼起来即"认证低秩注意力"——从纲领变定理。

### A3. 工件：KV 逐行审计日志（M2 完成后）

torch 侧 hook：每层每行记录 (dropped_energy, 签发的界 2√ε·V_max)；
exe/FFI 侧提供检查器。这是 proof-carrying inference 的第一个可运行工件，
论文的"运行时凭证"截图/日志来源。

## 路线 B：实例 Gershgorin 框架证书（C>25 空洞的真正解法）

### B0. 设计中发现的坑（先读，否则会撞墙）

**⚠️ 全 m=128 梯子的实例 Gram 在窗口 N 内是退化的。** 截断窗口内列范数
‖ψ_j‖² = min(1, N/n_j)：n_j ≫ N 的频带在窗口内近似常数/线性斜坡，范数 ≈ N/n_j → 0。
m=128（n 到 10^77 量级）整梯子在 N=512 下接近线性相关——**对全梯子做 Gershgorin
会得到平凡下界，这不是 bug 是数学事实**。

**正确设计：证书是"窗口自适应子梯子"的**：
1. 给定窗口 N，取可见频带 n_j ≤ N（N=512 时即 3,13,53,213——恰是 E2 里
   psi-trunc 保留的四个！）；
2. 对该子梯子（列范数=1）做 Gershgorin；
3. 长频带不进证书（它们的作用是模型内部的，不承担框架保证）。

**这个坑反而深化了叙事**：E2 实验证实 psi-trunc（n_j≤T_train）外推更优 +
实例证书只认证 n_j≤N 子梯子 —— **"经验上该留的频带"与"定理能保的频带"是同一批**。
理论与实验在这里第三次对齐（前两次：截断机制、相对化方向）。

### B1. Gershgorin 框架引理（参数化 μ 版，纯数学）

```
gershgorin_frame :
  (单位向量系 {ψ_i}) -> (forall i, SUM_{j≠i} |<ψ_i, ψ_j>| <= μ) -> μ < 1 ->
  (1-μ)||c||² <= ||Σ c_i ψ_i||² <= (1+μ)||c||²
```
证明：上界用 |⟨ψ_i,ψ_j⟩| ≤ g_ij + Cauchy-Schwarz 对交叉项；下界三角不等式。
**经典框架引理（Gabor 框架文献标准结果）**，全部用现有内积机器可证。
关键：μ 是**实际计算的量**，不是最坏情形 K(C)=1/(√C−1)。

### B2. Dirichlet 闭式 + 实例计算

**闭式（Coquelicot 的 cos/sin 可达）**：对频差 Δ_ij = 1/n_i − 1/n_j，
```
|<ψ_i, ψ_j>| = |sin(πNΔ) / sin(πΔ)| / sqrt(n_i · n_j)
```
（有限几何和的标准恒等式；sin(πΔ) ≥ 2Δ 当 Δ ≤ 1/2，防除零。）

**手算预估（待实例计算核实，n_j≤N=512 子梯子，N=512）**：
- 相邻对 |g| ≈ 0.14–0.17（(3,13): ≈0.17；(13,53): ≈0.14；(53,213): ≈0.16）；
- 间隔 s=2 对 ≈ 0.02–0.05；s≥3 可忽略；
- **预估 μ ≈ 0.35–0.45**（每行两个相邻对主导）。

**若成立 ⟹ 框架界 1±μ ≈ [0.55, 1.45]，C=4 梯子的可见子梯子直接非真空**——
不需要 C>25，不需要参数化子框架抽取。论文主张从"存在 C³≈64 的可证明子梯"
升级为"**实际使用的 C=4 梯子在窗口 N 内带实例证书**"。

**实例验证方式**：CoqInterval 的 interval 战术对 4×4 子梯子的闭式表达式直接
给出 Rigorous 界（12 对，每对一个 |sin/sin|/sqrt 表达式）——这是可判定的
小计算，不是数值实验。若 interval 战术对大 N 的 sin(πNΔ) 精度不足，
回退：手算上界 |sin| ≤ 1 + sin(πΔ) ≥ 2Δ ⟹ |g| ≤ 1/(2Δ√(n_i n_j))（保守但闭式）。

### B3. 反射层 + 提取（与主线 2 合流）

```
frame_check_instance : 梯子列表 -> 窗口 N -> bool   -- 可判定检查器
frame_check_true_gershgorin : frame_check_instance L N = true ->
  (1-μ_L)||c||² <= ||Σ c_i ψ_i||² <= (1+μ_L)||c||²   -- 检查通过 ⟹ 框架界
```
与 greedy_indices 的关系：门控从"抽 C³ 子梯"升级为"抽**实例可认证**子梯"
——对任意表达性频率集（包括未来学到的），检查器签发实际常数。
提取链（PSA_extract → OCaml → FFI）追加 frame_check_instance。
**这是"门控=证书签发"叙事的最终形态：签发的不是最坏情形常数，是实例常数。**

## 路线 C：位置 logit 一致有界性（T5+，安全签名的定理化）

**闭式常数链（全部可证）**：
```
||φ(k)||² = Σ_j (cos² + sin²)/n_j = Σ_j 1/n_j <= (1/3)(1+1/4+1/16+...) = 4/9
⟹ ||φ(k)|| <= 2/3   对一切 k 成立（与 T 无关！）
⟹ 位置对任意 logit 的贡献 <= (2/3)² · ||W_Q·P||_F · ||W_K·P||_F
```
定理形态：
```
positional_logit_bound :
  |q_i·k_j 的位置分量| <= (4/9) * ||W_Q P||_F * ||W_K P||_F
  -- 对一切位置 i,j、一切序列长度 T 一致成立
```
**需要的新基础设施**：MatrixNorm 迷你模块（Frobenius 范数定义、次乘性
‖AB‖_F ≤ ‖A‖_F‖B‖_F（Cauchy-Schwarz 可证）、算子范数 ≤ Frobenius）。
⚠️ 动工前先查 lib-构造性/22 库是否已有矩阵范数理论（避免重复造轮 + 触发 22 库重建）。
若 22 库已有：只引用不新建。

**与 E2 数据的连接**：psi/dense 比率全程 0.84-0.90、无 NaN——本定理是它的白盒解释：
位置通道的贡献被一致常数封顶 ⟹ 退化有界。论文"外推安全"小节的定理锚点。
（诚实边界：封顶的是位置分量，不是总 logit——总界还受 token 分量影响，如实表述。）

## 路线 D：频率分离泛化 + psi-rope 核族正交性

### D1. 前提泛化（重构为旁支，不动现有 81 项）

现有证明真正用的是频率间隔，不是几何性。新增（不重写旧的）：
```
-- 泛化引理：显式频率间隔前提
decay_bound_sep : (forall i<j, |1/n_i - 1/n_j| >= sep(i,j)) -> <相干性界 as sep 的函数>
```
文献锚点：Sidon 集 / B₂[g] 集 / Rudin 的 ℤ 调和分析（工作区复分析本行）。
生成器（4n+1）从定理前提降级为"满足分离条件的默认实例"。

### D2. psi-rope 核族正交性（与 psi-rope 实验同步交付）

```
kernel_orthogonality :
  n_i ≠ n_j（整数波长）-> 在整周期平均下
  <cos(2πd/n_i), cos(2πd/n_j)>_d = 0,  <cos, sin>_d = 0
```
（整数频率的单位根几何和恒等式——**与栈内 Dirichlet 机器同源，证明零件复用**。）
推论：psi-rope 梯子 = 相对核空间的**正交分解**，投影无条件收敛（无需框架条件）。
这是"RoPE 的梯子带证书"的定理本体，与 psi-rope 实验互为地基——**建议同会话交付**。

### D3. 饱和偏置族条件数（软滑窗提案的证书）

{1−cos(2πd/n_j)} 族的 Gram/条件数（同 D2 机器）——支撑层级软滑窗变体实验。
