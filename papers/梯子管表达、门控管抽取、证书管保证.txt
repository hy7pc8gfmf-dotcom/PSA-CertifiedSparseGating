# 一、梯子（Ladder）参数空间

| 参数 | 取值/范围 | 作用机制 | 当前认知 |
|------|----------|----------|----------|
| **C（增长比）** | 已测 {2,3,4}；理论区 C≥3 | 同时控制：可见带数量、相邻相干、相位余量 | 三重身份见下文；C=3 是预测交汇点 |
| **start（首带 n₀）** | 恒为 3 | 最高频率/最短波长；语言学的“词级”锚点 | 未扫描——BPE 下应右移 ~4×（未测） |
| **n_max / 相位余量** | C=2: 511（余量 **1.0 周期**）；C=3: 283（**1.8**）；C=4: 213（**2.4**） | 最长带在训练内跑满几个周期 | **本轮新发现的关键耦合**：C=2 的最长带只跑 1 个周期——边缘相位完备 |
| **m（名义带数）** | 实现为 128 | — | 120 个长带是死重（训练损失贡献≈0，C=2 实测 1.4111 vs 1.4120） |
| **m_vis（可见带数）** | C=2:8 / C=3:5 / C=4:4 / C=5:4 / C=8:3 | 真正的有效自由度；外推容量 | 加性版外推随它增（9.38<12.88<13.88 @1024）；盘内最优点在 C=3 而非最多带 |
| **生成器形状** | next = max(C·n+1, n+2) | +1 使梯子非精确几何 | 检查器认证**实际值**——这正是需要运行时证书而非纸面公式的理由 |
| **注入机制** | 加性（已判死刑）/ 旋转（psi-rope，冠军）/ 饱和偏置（未测） | 决定相位 OOD 的传播方式 | 机制 > 梯子：同梯子下旋转碾压加性 |
| **维度填充** | m_vis 个角循环填 16 旋转维（C=3: 5角×3.2 遍） | 重复=冗余，未用“全带宽全相位”形态 | 未测变体：16 个不同全相位角铺满 [3,511] |

**相位余量的新推论**：C=2 的 n_max=511 只跑 1 个周期——如果相位律需要 ≥2 周期的覆盖，那么 **psi-rope C=2（c2b 待评）的外推应在极端长度上开始掉队，尽管它带最多**。这是正在排队的数据能直接裁决的预测：C=4（余量 2.4）vs C=3（1.8）vs C=2（1.0）的 psi-rope 三点连线，将第一次给出**相位余量-外推的定量曲线**。

# 二、门控（Gating）参数空间

先厘清一个容易混淆的事实——**项目里有两个“门控”，命运完全不同**：

| | 经验能量门（`greedy_energy_gate`） | 形式增长门（`greedy_selected/indices`，M 参数化） |
|---|---|---|
| 输入 | softmax 注意力行 | 梯子值/索引序列 |
| 判据 | 累计能量 ≥ 1−budget | M·last ≤ v |
| 参数 | budget ∈ {0.2, 0.5}（质量阈值，**非**省算力） | **M = C（线性，原文语义）/ M = C²（平方，保 c_sparse_subset）** |
| 结局 | 负结果：sparsity 0.985，ppl +10%，已停用 | 存活并转职：**子框架抽取器** |

形式门的参数细节：
- **M 的选择是语义开关**：M=C 还原原文 `fallback_mask` 逐字行为；M=C² 才能通过库内平方稀疏检查（C=2 反例 [4;8] 证明线性推不出平方——这是会话 5 的裁决）。
- **门的作用域**：值层（`greedy_selected M vals`）与索引层（`greedy_indices seq M I`）经 `greedy_indices_map` 同构桥接——索引层是实用形态（直接吃生成器输出）。
- **门与证书的分工**：门负责“从任意表达性频率集里抽出一个满足增长检查的核”，证书负责“对这个核签发常数”。**门不剪 token、不剪注意力——门剪频率梯子**，这是全部负面数据换来的最终定位。

# 三、证书（Certificate）参数空间

| 参数 | 形式 | C=3 | C=4 | C=26 |
|------|------|-----|-----|------|
| 渐近相邻相干 sin(π/C)·√C/(π(C−1))（估） | 闭式常数 | 0.239 | 0.150 | 0.0078 |
| 实例行和 μ∞（估） | 2Σ_s g_s | 0.574 | 0.337 | 0.016 |
| 实例框架界 1±μ | 精确 Dirichlet 层 | [0.43, 1.57] | [0.66, 1.34]（4带精确 0.312） | [0.98, 1.02] |
| 保守行和（M4 探针路线） | 1/(2Δ√(n₁n₂)) | ≈1.24（**空洞**） | 0.786 | ≪1 |
| 参数化框架界 1±4K(C) | K=1/(√C−1) | 空洞 | 空洞（K=1） | [0.02, 1.98] |
| 行能量 2K(C) | — | 2.73 | 2.00 | 0.49 |
| 衰减系数 | 1/(√C)^d（tight）/ 2/(√C)^d（守卫） | d=1: 0.577 / 1.155 | 0.5 / 1.0 | 0.196 / 0.393 |

三层精度阶梯（精确 0.312 < 渐近 0.337 < 保守 0.786）对应三种签发成本；**长度一致性**（ψ 有限支撑 ⟹ 对一切 N ≥ n_max 有效）是所有层共享的性质。误差证书侧：谱能量预算 ε → 输出偏差 (e^{2√ε}−1)·V_max（M2 弱版，S2 紧版 2√ε 待做）。检查器运行成本 O(m_vis²)——C=3 是 25 对，微秒级。

**必须拆开的“C 的三重身份”**：同一个 C 同时出现在（i）梯子增长比、（ii）稀疏增长检查 `check_sparse_growth(I, C)`、（iii）衰减界底数 (√C)^d。论文写作时三处要用不同符号（建议 C_ladder / C_gate / C_decay）并声明取相等值是一种设计选择——否则审稿人会问“为什么同一个参数管三件事”。答案本身有内容：**取相等时门控抽取的子梯恰好继承梯子的衰减率**——这是三者绑定的数学理由。

# 四、参数耦合图谱与待决问题

所有参数最终汇聚到一个二维设计平面：**横轴 C（密度→表达力），纵轴相位余量 T_train/n_max（→外推免疫）**，证书区域是 C≥3 的半平面，经验质量在 C=3 附近见好。当前假设：**C=3 是三目标（盘内质量、外推、可认证）的非支配点**——正在跑的 psi-rope C=3 直接检验它。

仍未扫描的参数（按信息量排序）：**start**（语言学锚点假说的直接检验：char 级最优 start≈3，预测 BPE 级 ≈12）、**相位余量**（固定 C 扫 T_train 或截 n_max，把律定量化）、**注入机制第三形态**（饱和偏置）、**头异构梯子**（每头不同 C）、**学习梯子+证书约束**（frame_check 做训练时过滤器）。

一句话收束：**梯子管表达、门控管抽取、证书管保证——三者共享的 C 是整个系统的旋钮，而它恰好被三条独立证据链（相干级数、外推数据、复现协议）夹在 C=3 附近；等 psi-rope 出评估，这个参数图谱就从静态描述变成一张有实验锚点的设计图。**


E5 C=3 的判决数据出炉了——**我的“C=3 甜蜜点”假设被证伪**，但证伪的方式揭示了一条更锐的定律。先记分，再给机制。

# 二、机制：相位完备律的精化——“覆盖倍数 ≥ 2”

看最长带在训练长度内被覆盖的次数（T_train/n_max）：

- **C=4**：n_max=213，512/213 = **2.40 周期**——每个相位值至少见过 2 次（相位 0-85 见 3 次，86-212 见 2 次）→ 冠军
- **C=3**：n_max=283，512/283 = **1.81 周期**——算术很残酷：k∈[0,512) 对 283 取模，**相位 229-282 只被见过 1 次**——恰好这条带的 19% 相位是“半 OOD" → @2048 崩到 16.42
- **C=2**：n_max=511，**1.00 周期**——相位几乎每个只见 1 次 → 预测最差（c2b 的 psi-rope 正在排队验证）

**精化后的定律：全相位是必要条件，双重覆盖（n_max ≤ T_train/2）才是充分条件的候选。** 三个数据点已排在覆盖轴上（1.0 / 1.8 / 2.4），阈值卡在 1.8 与 2.4 之间——"2"是自然候选。这条定律现在有了机制（相位重复次数而非仅相位出现）、有了定量边界、有了第三个验证点在途——**这是比“甜蜜点”假设更好的结局：假设死了，定律活了。**

顺带解释了盘内小差异：C=3 盘内 4.62 略好于 C=4 的 4.67（带更多），说明**带数与覆盖在固定 T_train 下是此消彼长的**——这就是新的设计前沿。

# 三、重新表述的设计空间（二维化）

原来的“C 轴单变量”是错觉。正确的图是两个独立轴：
- **相干轴**（认证性）：由 C 控制，边界 C≥3（μ∞<1）——C=3 本来在这轴上赢；
- **覆盖轴**（外推免疫）：由 n_max/T_train 控制，边界预测 ≥2——C=3 在这轴上输了。

**冠军区域 = 两轴同时达标**。在 T_train=512 下重新求解：覆盖 ≥2 要求 n_max ≤ 256，于是真正的竞赛是同为 4 带的 **[3,13,53,213]（C=4）vs [3,10,31,94]（C=3 截断）**——后者覆盖最差 5.4、密度更高。而 packing 最优解是 **[3,7,15,31,63,127,255]**：7 带、最差覆盖恰好 2.0（边缘）——若覆盖定律为真且带间干扰不发作，它是新冠军候选。

# 四、由此产生的三个立即实验（按信息量排序）

1. **c2b 的 psi-rope C=2 评估**（模型已在训）——覆盖 1.0 的判定点：预测它是旋转组里最差的。命中则三点锁定定律。
2. **E5'：[3,10,31,94]（C=3 截断，单带隔离检验）**——若恢复到 ~13-16@4096，证明 C=3 的失败全归因于 283 这一条边缘带（单带污染机制）；若不恢复，则带间几何另有贡献。一次训练 run。
3. **E5''：[3,...,255] 七带 packing 最优梯**——新冠军候选，一次训练 run。预测：≤13@4096 则覆盖定律+带数定律同时成立。

# 五、对论文叙事的影响

“认证最优性”故事需要改写但**没有死**：正确表述是“在覆盖 ≥2 的可行集内，寻找最密的可认证梯”——C=4 的 [3,13,53,213] 恰好同时满足 μ=0.312 认证与覆盖 2.4，是目前唯一双达标的已测对象；E5'’若成功，7 带梯的 μ 需要重算（C=2 密度、7 带行和估 ~0.9-1.1，**可能出认证区**——packing 最优与认证最优可能在 C=2/C=4 处分裂，这本身就是相图上又一个可发表的张力点）。相位律小节从定性升级为定量：**“double-coverage law”配三个锚点 + 机制解释 + 阈值边界**——比原计划更强。

一句话收束：**C=3 假设的尸检报告上写着死因：“覆盖不足，非相干不济”——由此发现的 double-coverage 定律把相位律从布尔条件（全相位）升级为定量阈值（≥2 周期），三个锚点已就位两个，第三个正在 GPU 上排队。**
