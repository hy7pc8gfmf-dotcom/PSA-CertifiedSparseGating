## 三、定理与模块扩展清单（核心交付）

### T1 `FrameCheckSafeDomain.v`——安全域谓词形式化（P0，最大攻击点的闭合）

```coq
Definition safe_for_int63 (I : list nat) : Prop :=
  (forall n, In n I -> n < 2^53) /\ (pair_den_bound I < 2^63).

Theorem safe_domain_sound :
  forall I, safe_for_int63 I ->
    frame_check_instance I = frame_check_int63_model I.
```

- **性质**：完整证明（**禁 Admitted/Conjecture**——Conjecture 会进 Print Assumptions 污染 165 项审计；等价性方向需把 OCaml int63 语义在 Coq 中建模，`Int63` 库或 `Z` + 界内无溢出引理）
- **依赖**：现有 `pair_den` 乘积极限（已在 §6 量化：累积分母 ≤ ∏ pair_den）；`Int63`（Coq-stdpp 或 micromega 的 word 库）
- **工作量**：2–3 天 ｜ **venue 收益**：直接回应四轮评审共同的第一攻击点；CPP 标准 2（替代方案：为何不直接 Zarith——答案两写：Zarith 提取为工程路线、安全域为证明路线）
- **验收**：独立编译 EXIT=0；Print Assumptions 全 Closed 或仅 Dedekind 三公理；对 114 阶梯扫描全部实例可判定

### T2 `FrameCheckGraduated.v`——分级证书（P1，Distinguished 冲击项）

```coq
Inductive cert_level := L1_tight | L2_composite | L3_energy_only | L4_rejected.

Definition frame_check_graduated (I : list nat) : cert_level := ...

Theorem frame_check_graduated_sound :
  forall I lvl, frame_check_graduated I = lvl ->
    match lvl with
    | L1_tight => gershgorin_frame_mu I (4/5)
    | L2_composite => composite_frame_bounds I
    | L3_energy_only => energy_upper_bound I
    | L4_rejected => True
    end.
```

- **依赖**：`probe_robust.v` 容错 Gershgorin（坏对 ≤ δ·n ⟹ 行和 ≤ n·(μ+δ)）作 L2 判定子；`champion_e5_composite_certificate` 骨架作 L2 实例
- **工作量**：3–4 天 ｜ **收益**：[3,7,15] 类假阴性从"拒绝"变"降级服务"；七带从手工复合证书变自动分级输出——检查器方法论从二元升级为分层服务
- **验收**：114 阶梯扫描重跑分级分布表（L1/L2/L3/L4 计数），E5'' 自动落在 L2
