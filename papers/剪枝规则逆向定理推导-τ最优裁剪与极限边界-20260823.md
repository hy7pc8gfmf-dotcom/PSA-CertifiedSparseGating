# 剪枝规则逆向定理推导：τ 最优裁剪与极限边界（2026-08-23）

> 目的：从经验剪枝规则 `--rand-max 384`（外推 7.50 → 5.36）**逆向推导**出背后
> 未被证明的定理族，以及「提升的极限边界」对应的最终定理。
> 依据：batch3/4 数据（s1337，27000 iters）+ 论文 A 现有定理（碰撞/τ/框架/核漂移）。
> 方法：观测 → 数学模型 → 遗漏定理 → 形式化可行性分级。

---

## 0. 观测数据（逆向推导的起点）

| 配置 | 裁剪点 N（保留 n ≤ N） | @4096 ppl | 窗内最小周期数 T/N |
|---|---|---|---|
| rand（τ 全保留） | 511 | 7.50 | 512/511 ≈ 1.002 |
| **randmax384（最优）** | 384 | **5.36** | 512/384 ≈ 1.333 |
| randmax256（过剪） | 256 | 8.44 | 512/256 = 2.0 |
| ogrid（结构化） | — | 19.30 | — |
| ALiBi（无碰撞基线） | — | 2.11（平坦） | ∞（无周期） |

**经验规律**：外推性能 P(N) 作为裁剪点的函数是**倒 U 型**（数值越低越好）：
P(256) = 8.44 > P(384) = 5.36 < P(511) = 7.50。存在**最优裁剪点 N\* = 384 ≈ 0.75·T**。

## 1. 逆向数学模型（把拍脑袋翻译成数学）

**设定**：训练窗 T（512），外推长 L = k·T（k = 8）。频率集 F = {n_1,…,n_m}（波长，n_j ≤ T），
旋转 θ_j = 2π/n_j，位置编码 v(t) = (cos(tθ_j), sin(tθ_j))。裁剪 = 保留 F ∩ [1, N]。

**三个关键量**（逆向推导出的核心对象）：

1. **窗内周期数**：c(n) = T/n——带 n 在训练窗内完成的周期数。c(n) < 2 时该带在窗内
   不完成两周期，其特征 {cos(2πt/n), sin(2πt/n)}_{t<T} 在窗内**近似低秩**（相位片段
   接近线性/常数），模型易把它学成「常数偏置或线性函数」而非周期结构。

2. **过拟合代价**：带 n 的窗外失配 ∝「窗内学到的东西」与「真实周期结构」的差。
   当 c(n) 小（n 接近 T），窗内相位片段单调，线性近似误差小 → 模型精确拟合窗内片段
   （**过拟合**）→ 窗外沿用线性外推，与周期延续失配 → 外推误差大。

3. **结构价值**：带 n ≤ N\* 提供中频周期结构（窗内 ≥ 1.33 周期），支撑远距离外推的
   相位延续。剪掉它们 → 失去结构（256 恶化）。

**最优裁剪点的平衡**：N\* 是「过拟合带（n ∈ (N\*, T]，窗内周期 < c\*）」与
「结构带（n ≤ N\*，窗内周期 ≥ c\*）」的分界。实验值 c\* = T/N\* = 512/384 ≈ **4/3**。

## 2. 遗漏定理清单（从剪枝规则反推）

### T1. 外推损失的形式化定义（**根基缺失**）
- **陈述**：∀频率集 F、训练窗 T、外推长 L，定义 ExtLoss(F, T, L)。
- **现状**：外推性能只有经验 ppl，**无定理级定义**——没有定义就无法证明「裁剪改善外推」。
- **衔接**：论文 A 已有 `kernel_drift_controls_attention`（核漂移 ≤ dc ⟹ softmax TVD ≤ e^{2dc·dd}−1）
  与 `kernel_identical_tvd_zero`——核漂移正是「训练窗核 vs 外推核」的差，可直接用作
  ExtLoss 的上界（ExtLoss ≤ e^{2·drift}−1）。
- **可行性**：◐ 部分可证（借用核漂移链；「核漂移 ⟺ ppl」仍缺桥梁）。

### T2. τ 最优裁剪存在性（**U 型曲线定理**，本次提升的核心）
- **陈述**：∀T, L, F，裁剪函数 N ↦ ExtLoss(F ∩ [1,N], T, L) 存在极小点 N\*(T, L, F)。
- **支撑引理**：
  - **T2a（裁剪单调性）**：存在 N\* 使：n > N\* 的带剪掉 ⟹ ExtLoss 下降（过拟合带）；
    n ≤ N\* 的带剪掉 ⟹ ExtLoss 上升（结构带）。
  - **T2b（过拟合带刻画）**：带 n 过拟合训练窗 ⟺ c(n) = T/n < c\*（窗内周期 < 阈值）。
- **可行性**：◐ T2a 部分可证（碰撞质量单调：剪掉 n>N 后 Στ(n) 单调降，已有 tau 刻画）；
  T2b 需「过拟合」的形式化（见 T3）。

### T3. 相位冗余定理（过拟合的定量机制，T2b 的依据）
- **陈述**：带 n 在窗内周期数 c(n) 越小，其窗内特征集的**张成秩/框架下界越低**
  （相位片段越接近低维子空间），模型对该带的可拟合复杂度越低 ⟹ 过拟合风险越高。
- **形式化对象**：窗内特征集 F_n = {v_n(t)}_{t<T}（n 维旋转特征），其框架界
  m·(1−δ) ≤ Σ|⟨x, v_n(t)⟩|² ≤ m·(1+δ)。c(n) 与框架界的关系可定量：
  c(n) ≥ 2 ⟹ 特征集含完整周期，框架紧；c(n) < 2 ⟹ 框架退化。
- **衔接**：论文 A 的框架理论（gershgorin 界、`abstract_unconditional_basis`）可直接套用。
- **可行性**：✓ 最接近可证——框架界对 T/n 的单调性是纯线性代数 + 傅里叶。

### T4. 极限边界定理（**最终定理**：提升的极限）
- **陈述（τ 感知频率选择的极限）**：给定 T、外推倍数 k = L/T、频率容量 m，
  带证书方案的最小外推损失下界 L_min(k) 由「保留窗内周期 ≥ c\*(k) 的带 + 稠密覆盖」达到；
  当 k → ∞，L_min(k) 收敛到有限常数（**有限极限**）；且对任意 k：
  **L_min(k) > L_无碰撞**（ALiBi 平坦曲线为极限基准）。
- **含义**：5.36 不是终点，但**收敛于 > 2.11 的下界**——周期结构方案（带证书）与外推极限的
  差距由「周期参数化固有碰撞」决定，不可通过裁剪消除（与论文 A 的「可证性-外推性双轨分离」
  `稠密覆盖 ⟹ μ≤4/5 不可证` 一致）。
- **支撑**：T2（最优裁剪）+ 稠密覆盖帕累托（已有）+ 碰撞质量单调（已有 τ 刻画）。
- **可行性**：✗ 整体需 T1（损失定义）+ T2；但「裁剪后碰撞质量单调」「稠密覆盖保持」可先证。

## 3. 最终定理的精确陈述（极限边界）

> **定理（τ 感知频率选择的极限边界，推测）**：设训练窗 T、外推倍数 k、频率容量 m。
> 存在常数 c\*(k)（实验 ≈ 4/3，理论待定）与 N\*(T,k) = T/c\*，使得带证书方案的
> 外推损失满足：
>
>   ExtLoss_最优(F, T, kT) ≥ L_无碰撞(k) + δ_certified(k)
>
> 其中 L_无碰撞(k) 是 ALiBi 类无周期方案的平坦损失，δ_certified(k) > 0 是周期参数化的
> 固有代价（碰撞负债），且 lim_{k→∞} δ_certified(k) = δ_∞ > 0（**极限不可消除**）。
>
> 等号在「保留 F∩[1,N\*] 且稠密覆盖」时达到（当 T、m 给定）。

**可验证的推论**（实验可先验）：裁剪点应随外推倍数 k 移动（k 增大 ⟹ N\* 变化）；
多 seed 下 U 型曲线稳定；L 无限大时裁剪仍有极限收益（不归零）。

## 5. 与欧拉 Coq 的衔接（可选深化）

欧拉乘积式 ∏(1−p^{−s})^{-1} = Σ n^{−s} 的证明与频率阶梯**同构**：
- 素数 p ↔ 频率带 n（不可分解原子）
- 唯一分解（L3）↔ 频率集的张成
- **裁剪 p > N（取 smooth 数）↔ 裁剪 n > N\***——欧拉 L3/L4 的「有限乘积逼近」
  正是「剪掉大素数 ⟹ 尾项可控制」的**级数版**；τ 裁剪是「剪掉大波长 ⟹ 过拟合可控」的
  **谱版**。两者共享「截断-尾部控制」的抽象：**截断尾部误差 ≤ 可控量**。
- 若把 T2a 形式化，其「尾部单调」结构与欧拉「尾部 Σ_{n>N} n^{-s} ≤ 1/N」同源
  （ζ 尾部界，L4 准备中）。

## 6. 结论

`--rand-max 384` 的「拍脑袋」背后遗漏了**三个定理族**：
1. **T2（τ 最优裁剪存在性）**——U 型曲线的数学依据（裁剪点不是玄学，是变分问题）
2. **T3（相位冗余/过拟合刻画）**——为什么 384 而非 256/511（窗内周期阈值）
3. **T4（极限边界）**——提升的极限：5.36 → 收敛于 > 2.11 的下界，周期参数化固有代价不可消除

**最接近可证的**：T3（框架界 vs T/n，纯傅里叶）与 T2a（碰撞质量单调，已有 τ 刻画）——
这两条把「拍脑袋」变成「定理」，是下一步形式化的首选。
