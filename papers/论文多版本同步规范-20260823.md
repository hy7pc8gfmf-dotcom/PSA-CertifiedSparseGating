# 论文多版本同步规范（2026-08-23 定稿）

> 规范编号：E113（经验卡体系，待登记 INDEX.md）
> 适用范围：`论文与文档/` 下论文 A / 论文 B 的三版本体系（草稿 / 中文规范版 / 正式版）
> 触发场景：修改论文内容（数值、命名、计数、结论、边界声明）时，必须按本规范同步全部相关版本
> 权威源：**中文规范版 = 母版**（内容修订的唯一主写点；正式版/草稿为派生副本）

---

## 1. 版本体系与职责

| 版本 | 文件命名模式 | 职责 | 可否直接编辑 |
|---|---|---|---|
| **中文规范版**（母版） | `*中文规范版*.md` | 内容修订主写点；保留版本历史、评审修订注记、作者列表、数据注记 | ✅ 唯一主写点 |
| **正式版**（投稿形态） | `*正式版*.md` | 面向投稿（TACL/CPP 等）的清洗副本；英文摘要/标题、无内部注记 | ⚠️ 内容修改须同步自母版；不引入母版没有的新内容 |
| **草稿**（工作态） | `*草稿*.md` | 最老的中间态；含会话/评审注记 | ⚠️ 仅同步计数/命名/数值口径，不精修措辞 |

**生成关系**：正式版由草稿"清洗"而来（删除会话/评审/版本内部注记）——**是手工操作，不是脚本**。
工作区内无"草稿→正式版"自动转换脚本；唯一的转换脚本 `md2docx_zh.py` 只做 md→docx 排版。

## 2. 同步铁律（修改任何论文内容时）

1. **母版优先**：先改中文规范版，再抄送正式版与草稿。禁止只改正式版而不改母版。
2. **内容三版一致**：数值（PPL/比值/计数）、命名（如 τ 裁剪 vs τ 感知频率选择）、结论口径
   （如 2.85× vs 30%）、边界声明（证书覆盖范围）在三个版本中必须一致。
3. **正式版不引入新内容**：正式版只能反映母版已有内容；若正式版与母版结构不同（章节编号不同），
   按内容对应关系同步，不照抄章节号。
4. **草稿只同步口径**：草稿的措辞/结构允许落后，但计数与命名必须对齐（避免读者混淆）。
5. **版本头注记**：母版每次修订更新版本号（如 v2.1→v2.2）并记录修订摘要；
   正式版/草稿头部标注"来源：XX 清洗"与同步日期。
6. **补丁文档驱动**：若已有补丁文档（`*更新补丁*.md` 或 `*更新补丁-*.md`），
   按其中 P1–P5 的目标文件清单逐文件执行，完成后勾选。

## 3. 已发生内容修订的类型（必须三版同步）

| 类型 | 示例 | 三版落点 |
|---|---|---|
| 数值修正 | 结论"30%"→"2.85×/2.78×"；"1-2 个 PPL 点"→"约 8 个点/比值 2.8×" | 摘要、结论、权衡段 |
| 命名降格 | "τ 感知频率选择"→"τ 裁剪（τ-trimmed reallocation）" | 摘要、§10.9、结论、版本头 |
| 计数统一 | τ 判决"6 个"→"7 个方向性正向判决（归并 4 个独立实证支点）" | §8.4、摘要、结论 |
| 定义补全 | E5'' 首现处定义（[3,7,15,31,63,127,255] = C=2 八带剪 511） | 引言首现处 |
| 边界声明 | 证书覆盖基表示层能量范数，不覆盖 PPL/外推性能 | 引言、§9 接口、摘要 |
| 语义修正 | 裁剪语义 = 64 维循环填充整体重组（非单纯高频移除） | §10.9a、命名注记 |

## 4. 操作清单（修改后检查）

- [ ] 中文规范版已更新（含版本号 + 修订摘要）
- [ ] 正式版已同步（内容对应处）
- [ ] 草稿已同步（至少计数/命名）
- [ ] 全文搜索旧命名/旧数值确认无残留（如 `τ 感知频率选择`、`约为 30%`、`6 个正向`）
- [ ] 若涉及论文 A 联动（证书边界、形式化状态），同步论文 A 相关版本或标注待办
- [ ] 协同文档（`AI注意力算法/代理协同对话.md`）追加消息记录本次修订
- [ ] 有"不可表述为 X"的口径（如审稿要求不得写"1-2 个点"），在版本头或补丁文档留痕

## 6. 边界与例外

- **仅排版差异**（md→docx）无需三版同步，由 `md2docx_zh.py` 单独处理。
- **纯论文 A 内容**（不涉及论文 B）不强制同步论文 B 版本，但涉及"论文 A 证书边界/审计声明"
  时论文 B 引用处（如"165 项全零经典排中"）须同步标注修订。
- 若未来同事引入"正式版重清洗"脚本，本规范第 2 条仍适用：内容以母版为准，
  重清洗只影响格式不影响内容；若有冲突以本规范为准并更新本文件。
