## 0. 结论速览（三角结论）

- **C=4 梯子 `[3,13,53,213]`：长度轴机器证据完备。** `certified_c4_frame_bounds_anyN`（`:3377`）显式证明对**一切 N ≥ 214**，框架界 `[1/5, 9/5]` 成立。这是"表示稳定性对所有长度不变"的**真·长度外推证书**。
- **T8 核梯子 `[3,15,63,255]` / E5'' 七带：长度轴聚合证书缺失。** `certified_t8_core_frame_bounds`（`:3640`）是**固定窗口 M=256** 证书，**无 `_anyN`**；E5'' 七带 `champion_e5_composite_certificate`（`:5080`）同样固定窗口 255。但 6 个 pair 界（`pair_3_15` 等，`:3434–3539`）已机器证明为 N 无关（仅依赖 `psi_inner_cons_bound` 窗口无关保守界），故缺失的只是"行和聚合到任意 N"的定理——**机械上可补，非概念空洞**。
- **论文 B"证书止于表示稳定性"主张须改写**：对 C=4 该主张**低估**了机器证据（证书实已证明"跨所有长度的表示稳定性"）；对 T8/E5'' 该主张**成立但需加注**（固定窗口已证、任意长度聚合待补）。

## 2. 为什么 C=4 的 anyN 成立（推理链）

`certified_c4_frame_bounds_anyN`（`:3377`）证明：
```
∀N≥214, length coeffs=4 →
  (1-4/5)·S ≤ l2_norm_sq F (N-1) ≤ (1+4/5)·S
```
证明路径：
1. `c4_row*_gen`（`:3276–3372`）对每个 off-diagonal 行和，用 `pair_3_13 / pair_3_53 / pair_3_213 / pair_13_53 / pair_13_213 / pair_53_213`（这些在 `InstanceCertificate` 中由 `psi_inner_cons_bound` 窗口无关保守界 `≤1/(2Δ√(n1n2))` 证出）得到 `≤4/5`，且 N 仅作 `213≤N` 前置、`lia` 不 consume → **行和对所有 N≥213 一致 ≤4/5**。
2. `psi_unit_norm` 对角处处 =1（∀N>0）。
3. `gershgorin_frame_mu 4 ... N (4/5)`（`:3391`）以 N 为窗口聚合。

⇒ C=4 的"表示稳定性"是**长度不变**的，且这是 Coq `Qed` 机器证明。这正是长度外推在表示轴的数学底层：无需重训、无需改 θ、无需换 base，框架条件数 `(1+μ)/(1-μ)=9` 对任意上下文长度不变。

## 3. T8 / E5'' 的长度轴缺口（精确刻画，非泛化恐慌）

- **缺口范围窄**：不是"表示稳定性未证"，而是"表示稳定性对所有长度的聚合定理未写"。pair 级 N 无关界已全证（T8 六对；E5'' 需额外 15 对未证）。
- **T8 4 带可立即补齐**（见 §4 补丁）：其 6 个 pair 界齐备，照 `c4_row*_gen` 加 N 参数即可得 `certified_t8_core_frame_bounds_anyN`。
- **E5'' 7 带补齐成本更高**：21 个 off-diagonal 对中，仅落在 `{3,15,63,255}` 子集的 6 对被证；其余（如 `(3,7),(7,15),(7,31),(31,63),(31,127),(127,255)` 等 ~15 对）需新增 `pair_*` 证明。机械但非一行。
- **后果**：论文 B 若声称"E5'' 证书对所有长度成立"，目前**超出机器证据**；应降级为"固定窗口 255 已机器证明；任意长度聚合对 C=4 已证、对 E5'' 待补（pair 界 N 无关，结构上可推广）"。

## 4. 可直接粘贴的补证补丁（未编译验证 —— 本机无 coqc）

> 下列补丁镜像 `M4bLengthConsistency` 的 `c4_row*_gen` / `certified_c4_frame_bounds_anyN`，
> 作用于 `T8CoreCertificate` 的 `t8l`。**未经 coqc 编译**，请在你的环境 `Require` 后 `Qed` 验证。
> 注意：`pair_3_15` 等前置为 `3≤N`/`15≤N`/`63≤N`，统一取 `256≤N` 即全满足。

```coq
(* ===== T8CoreCertificate 内追加：长度泛化 anyN 证书 ===== *)

Lemma t8_row0_gen (N : nat) : (256 <= N)%nat ->
  sum_f_R0 (fun j => if eq_nat_dec 0 j then 0%R else
      Cnorm (Csum (fun k => psi (nth 0 t8l 0%nat) k *c Cconj (psi (nth j t8l 0%nat) k)) N)) 3
  <= 4 / 5.
Proof.
  intros HN.
  apply Rle_trans with (sum_f_R0 (fun j => match j with 0%nat => 0%R | 1%nat => 5 / 16 | 2%nat => 63 / 520 | _ => 85 / 1512 end) 3).
  - apply sum_f_R0_le_compat. intros j Hj.
    destruct (eq_nat_dec 0 j) as [H0 | H0n].
    + subst j. simpl. nra.
    + destruct j as [|[|[|[|j']]]]; try lia.
      * replace (nth 0 t8l 0%nat) with 3%nat by reflexivity.
        replace (nth 1 t8l 0%nat) with 15%nat by reflexivity. apply pair_3_15; lia.
      * replace (nth 0 t8l 0%nat) with 3%nat by reflexivity.
        replace (nth 2 t8l 0%nat) with 63%nat by reflexivity. apply pair_3_63; lia.
      * replace (nth 0 t8l 0%nat) with 3%nat by reflexivity.
        replace (nth 3 t8l 0%nat) with 255%nat by reflexivity. apply pair_3_255; lia.
  - simpl. nra.
Qed.

(* t8_row1_gen / t8_row2_gen / t8_row3_gen 同理，分别把窗口 255 改为 N、
   前置改为 256<=N，行和内界照搬 t8_row1..3（:3552/:3573/:3618 的 match 表），
   各 pair 调用 pair_3_15/pair_3_63/pair_3_255/pair_15_63/pair_15_255/pair_63_255。 *)

Theorem certified_t8_core_frame_bounds_anyN (N : nat) (coeffs : list Complex) :
  (256 <= N)%nat ->
  length coeffs = 4%nat ->
  let phi := fun i k => psi (nth i t8l 0%nat) k in
  let F := fun k => Csum (fun i => nth i coeffs C0 *c phi i k) 4 in
  let S := sum_f_R0 (fun i => Cnorm_sq (nth i coeffs C0)) (Nat.pred 4) in
  ((1 - 4 / 5) * S <= l2_norm_sq F (Nat.pred N) <= (1 + 4 / 5) * S)%R.
Proof.
  intros HN Hlen.
  cbv zeta.
  change ((1 - 4 / 5) * sum_f_R0 (fun i => Cnorm_sq (nth i coeffs C0)) 3 <=
          l2_norm_sq (fun k => Csum (fun i => nth i coeffs C0 *c psi (nth i t8l 0%nat) k) 4) (Nat.pred N) <=
          (1 + 4 / 5) * sum_f_R0 (fun i => Cnorm_sq (nth i coeffs C0)) 3).
  apply (gershgorin_frame_mu 4 (fun i k => psi (nth i t8l 0%nat) k) N (4 / 5)).
  - lia.
  - intros i k Hi Hk. destruct i as [|[|[|[|i']]]];
    (simpl; apply psi_ge_n_zero; lia) || exfalso; lia.
  - intros i Hi. destruct i as [|[|[|[|i']]]];
    (replace (nth _ t8l 0%nat) with _ by reflexivity; apply psi_unit_norm; lia) || exfalso; lia.
  - intros i Hi. destruct i as [|[|[|[|i']]]]; try lia;
    (apply t8_row0_gen + apply t8_row1_gen + apply t8_row2_gen + apply t8_row3_gen); lia.
  - exact Hlen.
Qed.
```

> 注：上述 `destruct ... (simpl; ...) || exfalso; lia` 是 `c4_row*_gen` 同构写法的紧凑转写；
> 若你的 Coq 版本对 `||` 战术链敏感，请照 `:3394–3412` 的显式 `destruct` 展开即可。
