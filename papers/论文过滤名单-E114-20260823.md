## 九、使用方式

1. **投稿前**：对正式版全文逐条过本名单（O1-O8 → C1-C8 → N1-N5 → V1-V5 → X1-X5）。
2. **修订时**：任何修改后运行 `_search.ps1` 类检索确认无禁用词残留
   （关键词：`零经典排中` / `任意阶梯的认证` / `τ 感知频率选择` / `1-2 个 PPL` / `30%` / `42 模块` / `7 探针` / `48 Qed` / `17 Qed`）。
3. **新增内容**：写入前先自查是否命中名单；新发现的问题条目追加到对应分类。
4. **两论文联动**：涉及论文 A 的审计/证书口径修订时，同步检查论文 B 引用处（X1-X5）。
