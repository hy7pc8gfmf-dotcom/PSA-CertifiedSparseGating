# 诚实性支柱实验设计（2026-08-19）：NoPE 控制 · NTK 基线 · E1 归因消融

> **用途**：推进侧工作单。三组实验 = 两篇论文（CPP 验证论文 + TACL 实证论文）的共同地基。
> **总原则**：先登记预测再跑（可证伪性）；判定树先写好再翻数据（防事后合理化）；
> 温控按 v2 协议（阈值 58/恢复 52 + 固定冷却）；**所有结论只在同协议 run 内比较**。
> **多 seed 纪律**：核心对照（dense / psi / psi-rand / psi-rope / psi-rope-rand）各 ≥3 seeds
> {1337, 42, 7}；报告均值 ± 标准差；单 seed 数字一律标注"单 seed 待复现"。

## 支柱一：NoPE 控制（诚实性闸门，最优先）

### 目的
回答"472k char 级模型到底需不需要位置编码"。若 NoPE 盘内不差且外推平缓，
全部位置编码叙事塌缩——必须最早跑、如实报。

### 实现（length_extrap.py 增改）
- 新增 `mode="nope"`：`forward` 中不加任何位置项（token_emb → blocks），
  其余结构与 dense 完全一致（n_layer/n_head/n_embd 相同）。
- 训练协议与 v2 完全相同：3000 iters，T=512，Gutenberg 5.1M，batch=32，温控。

### 预测登记（跑前写下）
- NoPE 盘内 ppl ≈ 5.6–6.5（差于 dense 5.40——char 级 LM 确实用位置信息）；
- 外推退化斜率介于 dense 与 psi 之间（因果掩码提供隐式局部性，但无远程位置结构）。

### 判定树
| 结果 | 结论 | 论文动作 |
|------|------|----------|
| NoPE 盘内 ≥ dense + 1.5 ppl | 位置信息必要性确认 | 正常推进；NoPE 表格入对照 |
| NoPE 盘内 ≈ dense（±0.3） | 位置贡献弱 | 主张收缩为"外推结构"叙事；盘内 -12% 淡化 |
| NoPE 盘内 < dense 且外推更平 | **闸门报警** | 叙事重构：位置方案价值仅在 BPE/更大规模（引 Kazemnejad et al. 2023 先例），如实报告 |

## 支柱二：NTK 基线（公平性支点，零训练成本，最先跑）

### 目的
工业界真对手是 rope+测试时频率修复（PI / NTK-aware / YaRN），不是裸 rope。
psi-rope 的冠军主张必须在"对手带修复术"的条件下重新检验。

### 实现（eval-only，复用 model_rope_b512.pt，不改训练）
在 `eval_at_length` 增加旋转角变换参数 `rope_variant`：
- **rope-PI**（位置插值）：θ′ᵢ = θᵢ / r，r = T_eval / T_train；
- **rope-NTK-aware**：base′ = base · r^(d/(d−2))，θ′ᵢ = base′^(−2i/d)
  （d = head dim = 32；高频几乎不动、低频拉伸——相位修复的工业标准形态）；
- 可选加臂：**rope-YaRN**（NTK-by-parts + 注意力温度 t = 0.1·ln r + 1），
  若实现成本高可推迟，PI/NTK 两个臂先出。
- 每个变体在 T ∈ {1024, 2048, 4096} 评估（r = 2, 4, 8），与 v2 表格并排。

### 预测登记
- rope-NTK @4096 显著优于裸 rope 20.28，预估落在 10–16 区间；
- **psi-rope（13.06，无测试时手术）与 rope-NTK 同级或更好（差距 ≤10%）**。

### 判定树
| 结果 | 结论 | 论文动作 |
|------|------|----------|
| psi-rope ≥ rope-NTK | 强主张成立："免调参 + 带证书还赢修复版" | 主结果表直接收录 |
| rope-NTK 领先 ≤15% | 主张改写为"同级，但免手术、免逐长度调参、带证书" | 诚实改写，仍可发表 |
| rope-NTK 领先 >15% | 冠军降级为"免维护的次优选择" | 定位收缩到证书 + 相位律 |

## 支柱三：E1 归因消融（-12% 的因果解剖，多 seed 核心）

### 目的
把盘内质量收益分解为两个候选机制：
**(a) 固定低维通道/信息瓶颈**（位置信息流经 2m 维固定特征，不可过拟合、参数少）；
**(b) 几何梯子结构**（多尺度波长匹配语言层级——匹配滤波器假说）。

### 消融矩阵（全部同协议训练，T=512）

| 臂 | 位置通道 | 检验什么 |
|----|----------|----------|
| dense | 可学习 wpe（65,536 参数） | 基线 |
| psi | 几何梯子 128 带固定特征 + 学习投影 | 现状 |
| **psi-rand** | **随机梯子**：m=128 个波长 log-uniform 采自 [3, 54613]（排序，seed 控制） | 同覆盖、同架构、同参数——只有几何性不同 |
| **psi-lin** | 线性梯子：波长线性铺 [3, 54613] | 规则但非几何 |
| **dense-frozen** | 固定随机高斯特征（2m×block）+ 同结构学习投影 | 去掉全部频率结构，只留"固定通道 + 瓶颈" |
| **psi-rope-rand** | 旋转角来自**随机全相位梯子**（波长 log-uniform in [3,511]，循环填充） | 外推冠军的几何归因：同全相位、随机 vs 几何 |

### 预测登记
- 盘内：psi ≈ psi-rand ≈ dense-frozen（三者都拿到大部分收益——瓶颈机制主导），
  psi-lin 略差或持平；
- **几何性在盘内的净贡献（psi − psi-rand）预估 ≤2% ppl**；
- 外推：psi-rope-rand 显著差于 psi-rope（几何波长匹配语言层级 → 相位能量分布
  更集中 → 外推更稳）——**这是几何假说真正的战场**。

### 判定树
| 结果 | 结论 |
|------|------|
| psi ≈ psi-rand，psi-rope ≫ psi-rope-rand | 最可能：瓶颈给质量、几何给外推——两个机制各管一头，叙事完整 |
| psi > psi-rand 盘内即显著 | 几何也给质量——匹配滤波器假说全面成立 |
| psi-rope-rand ≈ psi-rope | 几何死、全相位独活——相位律纯化，梯子设计论降级 |
| dense-frozen ≈ psi | 瓶颈全解释——频率结构叙事出局（相位律仍活） |

### 执行结果注记（2026-08-21 会话 18：b64 单 seed 初步 → b32 3-seed 确认 → E1 全臂收尾）
| 预登记 | 实测（@4096 ppl） | 判定 |
|--------|------------------|------|
| 外推：psi-rope-rand ≪ psi-rope（几何假说战场） | **psi-rope-rand 6.45±0.03（3-seed b32）< psi-rope C=4 12.75** | **证伪（反向，3-seed 坐实）**：旋转族 OOD 由相位完备/稠密覆盖主导，几何序无关 |
| psi ≈ psi-rand（盘内），几何净贡献 ≤2% | 盘内 4.53（psi-rand）vs 4.74（psi） | 盘内持平（psi-rand 反优 4%，趋势保留） |
| 外推：psi vs psi-rand 未预登记（嵌入族） | psi-rand 31.04±12.86（**高方差**：s42 16.21 / s7 37.83 / s1337 39.07，s1337 为 b32 补跑） | 嵌入族随机梯子 OOD 高方差；几何序给稳健性非绝对优势 |
| psi-lin 略差或持平 | **39.62±4.07（全臂最差）** | 线性铺频带破坏相位完备性，外推崩坏 |
| dense 基线 | dense 37.74（b64 s1337） | OOD 崩坏对照成立 |
| dense-frozen ≈ psi（瓶颈全解释） | **盘内 6.08±0.20 vs psi 系 4.5-5.0（+20-30%）**，外推 29.49±2.52 | **证伪**：固定高斯特征盘内掉质量——ψ 基频率结构对盘内质量有独立贡献（匹配滤波器假说部分成立） |
- **机制分层（3-seed 确认 + 全臂）**：旋转注入（相对位置）= 稠密相位覆盖取胜（随机亦优）；
  角度稠密度关键（rr 128 角 6.45 vs +rand 54 角 12.33）；绝对嵌入 = 频率结构给盘内质量、
  外推全崩（28-40 区间，仅几何序降方差）；两族分离。
- **冠军裁决逆转**：psi-rope-rand 6.45 < rope-NTK 3-seed 11.54±1.18（44%，p=0.018，d=−6.06）——
  免修复梯子方案重新登顶（论文 B §8/§10.5/§11 已改写）。
- **ΔCoh 预测因子被本次消融证伪**（4 点 R²=0.982 → 扩点后 R²≤0.1，重复带退化 + 稠密饱和）：
  仅稀疏无重复几何族内有效（论文 B §10.6 修正）。

## 论文映射（每根支柱堵哪个审稿意见）
- NoPE → "小模型可能根本不需要位置编码"（Kazemnejad 2023 一系质疑）；
- NTK → "你们的对手是 YaRN/NTK，不是裸 rope"（长上下文社区标准质疑）；
- E1 → "收益可能只是参数减少/正则化"（统计质疑）；
- 多 seed → "单 seed 噪声"（最低级也最常见的拒稿理由）。
