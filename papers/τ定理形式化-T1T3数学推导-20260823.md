## 1. T3 相位冗余：高频带窗内近共线（可严格证）

### 1.1 核心对象：窗内截断 Gram 矩阵

对带 n, m，定义**窗内相关**（Dirichlet 核）：

  G_T(n, m) := ⟨ψ_n, ψ_m⟩_T = Σ_{k=0}^{T-1} exp(i·k·(θ_n − θ_m))
            = exp(i·(T−1)Δ/2) · D_T(Δ)，  Δ := 2π(1/n − 1/m)

其中 D_T(Δ) = sin(TΔ/2)/sin(Δ/2)（Dirichlet 核）。

模长：|G_T(n,m)| = |sin(TΔ/2)| / |sin(Δ/2)|。

### 1.2 定理候选 T3a（高频带窗内冗余）

> 设 T ≥ 2，n ≥ m > T/2（即 c(n) ≤ c(m) < 2）。则窗内相关下界：
>
>   |G_T(n, m)| ≥ 2T/π · (1 − T·(1/m − 1/n)/2)·[修正因子]

**推导**：Δ = 2π(1/m − 1/n)（取正，因 m ≤ n ⟹ 1/m ≥ 1/n）。
n > T/2 ⟹ 1/n < 2/T；m > T/2 ⟹ 1/m < 2/T。
故 Δ/2 = π(1/m − 1/n) < π(2/T) = 2π/T ⟹ TΔ/2 < 2π。
- **sin 下界**：x ∈ [0, 2π] 时 sin(x) ≥ (2/π)x·(1 − x/(2π))（正弦下凸弦近似，可严格化：
  sin x ≥ 2x/π 在 [0, π/2]，x ∈ [π/2, 2π] 时 sin x ≥ 0 且 x·(1−x/2π) ≥ 0，需分区间处理）。
- **sin 上界**：|sin(Δ/2)| ≤ Δ/2（|sin x| ≤ |x|）。

组合：|G_T(n,m)| ≥ sin(TΔ/2)/(Δ/2) = [sin(TΔ/2)/(TΔ/2)] · T ≥ (2/π)(1 − TΔ/(4π))·T（在 TΔ/2 ≤ π/2 区间）。

**量级**：TΔ/2 = πT(1/m − 1/n) ≤ πT·(1/m − 1/(m+1))·(n−m) 等。最坏情形（n=m+1，n≈T/2 附近）：
TΔ/2 ≈ πT/(m(m+1))·… 当 m ≈ T/2：π·T/(T²/4) = 4π/T → 0（T 大时）。
⟹ |G_T| ≈ T（完全相关）。**高频带（n,m > T/2）窗内几乎完全共线**——相位冗余定量化。

### 1.3 定理候选 T3b（框架界退化，可复用 PSA 理论）

窗内特征集 Φ_T := {ψ_n(k)}_{n∈F, k<T} 的框架界（对系数向量 c）：

  A_T · Σ|c_n|² ≤ ‖Σ_n c_n ψ_n(·)‖²_T ≤ B_T · Σ|c_n|²

- **全相位带（c(n) ≥ 2，即 n ≤ T/2）**：窗内 ≥ 2 完整周期 ⟹ 近似正交（差频 Δ 满足 TΔ ≥ 4π，
  Dirichlet 核 |D_T| ≤ 1/sin(Δ/2) 有界）⟹ 框架近紧（A≈B≈T），可用
  `gershgorin_frame_mu`（行和 μ ≤ 4/5 ⟹ 界 [1/5, 9/5]，PSA_framework 已验证）。
- **冗余带（c(n) < 2，即 n > T/2）**：T3a 表明带间相关 ≥ 2T/π 量级 ⟹ Gram 矩阵行和
  μ ≥ |G_T|/T 大 ⟹ `gershgorin` 界失效（μ 超阈值）⟹ **框架退化**（A_T 下界崩塌）。
  **定量相变点**：μ(n) := Σ_{m≠n}|G_T(n,m)|/T 首次 ≤ 4/5 的 n 即框架可证紧的下界。
  当 T 固定、n 从 T/2 增大，μ(n) 单调增（T3a）——**存在 n₀ = T/c₀ 使 μ(n₀) 跨过 4/5**。

### 1.4 与 c* 的关系（判别）

- **理论相变点**：μ(n) = 4/5 对应的 c₀ = T/n₀（由 T3b）。这是「框架可证紧」的临界周期数。
- **实验最优**：c* = T/N* ≈ 4/3（batch4，27000 iters）。
- 二者**无需相等**：c₀ 是「冗余致框架退化」的几何阈值；c* 是「过拟合代价 vs 结构价值」
  的变分平衡（T2），还依赖 k 与训练轮数。**若 k 扫描显示 N*(k) 移动 ⟹ c* 是变分平衡点
  （深度论）；若 N*(k) 稳定且 ≈ T/c₀ ⟹ c* ≈ 几何相变点（弱常数论）**。

## 2. T1 外推损失定义：借核漂移（可严格化）

### 2.1 已有基础（论文 A 已验证）

- `kernel_drift_controls_attention`：核漂移 ≤ dc ⟹ softmax TVD ≤ e^{2·dc·dd} − 1。
- 核漂移 = 训练窗核 vs 外推核的差——正是「窗外失配」的度量。

### 2.2 定义候选 T1a（核漂移版 ExtLoss）

对方案 S（频率集 F 的裁剪规则）、训练窗 T、外推长 L：

  ExtLoss(S, T, L) := sup_{x∈域} TVD(κ_T(x), κ_L(x))

其中 κ_T / κ_L 为训练窗 / 外推窗的 softmax 核。由 kernel_drift：
  ExtLoss ≤ e^{2·dc(S,T,L)} − 1，dc 为核漂移常数。

**裁剪的净效应**（T2 的结构）：
  ExtLoss(裁剪 N, T, L) − ExtLoss(全保留, T, L)
  = [高频过拟合释放] − [结构丢失代价]
  两项均为 dc 的单调函数 ⟹ U 型曲线 = 两项交叉。

### 2.3 形式化可行性分级

- T1a 定义：✓ 可做（借用 kernel_drift 链，纯函数定义）。
- 「核漂移 ⟺ ppl」桥梁：◐（需要 ppl 的 loss 结构，超出 TVD 上界）。
- T2b（c(n) < c* ⟺ 过拟合带）：需 T3a（冗余 ⟹ 可拟合度低 ⟹ 过拟合风险）作中间层。

## 5. 理论判据的数值检验（2026-08-23，全部可复算）

### 5.1 gershgorin 框架 μ 判据 —— ✗ 不适用（负结果）

`t3_phase_transition.py`：带集 F = log_uniform(3,511,128,1337) 去重后 91 波长。
- 全带窗内 Gram 行和 μ(n) = Σ_{m≠n}|G_T(n,m)|/T：仅 n ≤ 13（c ≥ 39.4）满足 μ ≤ 4/5；
  全部裁剪点（256–511）的保留带集 max μ ∈ [15.5, 17.8]，**全部不可证紧**。
- **结论**：log-uniform 波长集小波长密集、差频小、窗内互相共振 ⟹ gershgorin 判据
  完全不适用来定位裁剪相变点。裁剪改善**不是**「框架正交性恢复」。

### 5.2 相位唯一性指标 —— ✗ 平滑，与实验阶跃不匹配（负结果）

窗内唯一相位比例：256→83.4%，384→97.1%，448→98.6%，511→99.8%——**平滑上升**。
实验却显示 448 与 511 阶跃差 0.64（3000 iters）。几何静态指标无法解释过拟合的阶跃。

### 5.3 ★ 64 维循环填充重组 —— 裁剪语义的关键发现

`psi_rope_theta`：ns = 未排序 ladder，idx = arange(64) % len(ns)。
- **裁剪改变 len(ns) ⟹ 64 维分配整体重组**（idx % 91 vs idx % 90 vs …），不是「剪高频维度」。
- 波长 491（c=1.043）在 64 维中出现 **0 次**（排第 91 位，未排序顺序）——full 与 rt448 的
  差异 = 整套旋转结构重组 + 少一个未用波长，而非「剪掉高频带」。
- **含义**：①「τ 裁剪 = 剪 n>N 的带」的叙事需修正为「裁剪 = 更换 64 维旋转结构」；
  ② 理论建模必须先固定「裁剪语义」（剪维度 vs 重排）；③ 加密采样不能只在 [448,511] 加
  波长（否则分配又变）——需全套对照。

### 5.4 过拟合机理的当前最佳假设

过拟合主犯 = **c(n) → 1+ 的带**（n → T⁻，窗内相位近乎全唯一、接近线性扫描，模型易把
「位置→相位」当线性映射记忆，窗外失配）。但唯一相位%平滑说明存在**阈值效应**
（c 低于某临界才「学会周期」），临界依赖训练轮数——这需要训练动态建模（T2 显式化），
非几何闭式。**理论侧短期无法闭式锁定 4/3**；实验侧 27000 iters 聚焦扫是当前最可行路径。
