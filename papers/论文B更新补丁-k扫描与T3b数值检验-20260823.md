## 1. k 扫描判别实验（K1–K5，确定 ✅）

**设计**：真训练（`--rand-max N`，训练时裁剪，与 batch4 同法）× 7 裁剪点 × k ∈ {1,2,4,8}。
配置：tinystories / block 512 / batch 32 / **3000 iters** / seed 1337（本地 RTX 3070，
温控 --gpu-max 80 --gpu-resume 75）。27000 iters 聚焦扫（rt448/480）进行中。

**结果**（ppl，CI95）：

| N \ T | 512 (k=1) | 1024 (k=2) | 2048 (k=4) | 4096 (k=8) |
|---|---|---|---|---|
| 256 | 2.68 | 2.89 | 3.08 | 3.83 [3.77,3.89] |
| 320 | 2.68 | 2.89 | 3.08 | 3.83 [3.77,3.89] |
| 352–448 | 2.68 | **2.86** | **3.04** | **3.80 [3.79,3.81]** |
| 511 (full) | 2.68 | 2.90 | 3.38 | 4.44 [4.43,4.45] |

**裁决**：
1. **N* 不随 k 移动**：最优区 [352,448] 在所有 k ≥ 2 稳定（k=1 时裁剪无差别）。
   ⟹ **弱常数论支持**（N* 是结构阈值，非 k 的函数）；深度论（N* 随 k 移动）被否定。
   （分辨率：352–448 间波长稀疏，N* 只锁定区间；4/3=384 在其中但未锁定。）
2. **full 显著差于裁剪**：@4096 4.44 vs 3.80，CI 完全不重叠（Δ0.64，17%）——
   **τ 裁剪主张独立复现**（不同设备、不同 iters 均成立；batch4 27000：7.50 vs 5.36）。
3. **收益随 k 放大**：@1024 Δ0.04 → @2048 Δ0.34 → @4096 Δ0.64（T4 推论预测之一）。
4. **256 过剪在 3000 iters 不显著**（3.83 vs 3.80，CI 重叠）；batch4 27000 下显著
   （8.44 vs 5.36）——**裁剪敏感度随训练轮数放大**（过拟合随训练加深）。

**论文建议措辞**（§10.9 增补）：
- τ 裁剪改善在独立复现（3000 iters 本地）下成立：full 显著差于裁剪（@8× Δ17%，CI 不重叠）；
- 最优裁剪区对 k 稳定（[352,448] 全 k 一致）——**支持裁剪点由结构决定，而非外推倍数**；
- 裁剪敏感度随训练轮数放大（3000 iters 弱 → 27000 iters 强）——与「过拟合随训练加深」
  机制一致；256 过剪效应在浅训练下被噪声掩盖（应表述为训练量的函数，非绝对）。

## 2. 理论数值检验（T1–T3，确定 ✅）

`t3_phase_transition.py`（可复算）：

### T1 gershgorin 框架 μ —— ✗ 不适用
带集 F = log_uniform(3,511,128,1337) 去重 91 波长。窗内 Gram 行和 μ(n) = Σ_{m≠n}|G_T(n,m)|/T：
仅 n ≤ 13（c ≥ 39.4）满足 μ ≤ 4/5；全部裁剪点（256–511）保留带集 max μ ∈ [15.5, 17.8]。
**结论**：log-uniform 小波长密集、窗内互相共振 ⟹ gershgorin 判据不适用来定位裁剪相变点；
**裁剪改善不是「框架正交性恢复」**。

### T2 相位唯一性 —— ✗ 平滑不匹配
窗内唯一相位比例：256→83.4%，384→97.1%，448→98.6%，511→99.8%——平滑上升；
实验却是 448 与 511 阶跃差 0.64。**几何静态指标无法解释过拟合阶跃**。

### T3 ★ 64 维循环填充重组 —— 裁剪语义修正（重要）
`psi_rope_theta`：ns = 未排序 ladder，idx = arange(64) % len(ns)。
- **裁剪改变 len(ns) ⟹ 64 维分配整体重组**，不是「剪高频维度」；
- 波长 491（c=1.043）在 64 维出现 0 次（排第 91 位）——full vs rt448 差异 =
  结构重组 + 少一个未用波长；
- **含义**：①「τ 裁剪 = 剪 n>N 的带」叙事修正为「裁剪 = 更换 64 维旋转结构」；
  ② 理论建模须先固定「裁剪语义」；③ 加密采样需全套对照（不能只加高频波长）。

**论文建议**：§10.9 机制讨论补一句（T3）："裁剪的实现语义是 64 维循环填充结构的整体
重组（波长列表长度改变 ⟹ idx%len 重排），其效应包含高频带移除与维度重组的混合——该
精细结构不影响裁剪改善的实验结论，但指出『剪高频带』为粗略叙事"。

## 3. 方法学（M1，确定 ✅）

掩码评估（加载全频率模型、评估时静音高频、保持维度分配）在所有 k 下全保留最优
（@4096 full 4.36 vs 静音 6.94）——**复现不了真训练的裁剪改善**。原因：模型训练时
适应全频率；评估静音 = 剥夺已用信息。**推论：裁剪改善是训练适应效应（非纯几何）**，
判别实验必须用真训练。论文可补一句方法学（避免读者误用掩码评估）。

## 4. 27000 iters 聚焦扫结果（2026-08-23 14:20，确定 ✅ 可写入正文）

**结果**（tinystories 27000 iters s1337，@4096，补 batch4 三点）：

| N | 256 | 384 | **448** | **480** | 511 (full) |
|---|---|---|---|---|---|
| @4096 | 8.44 | 5.36 | **5.15** | **5.15** | 7.50 |

- **N* @27000 ∈ [448, 480]**（rt448 = rt480 = 5.15 < 384 的 5.36）——最优裁剪点**右移**，
  **4/3 = 384 是三点扫描的局部最优而非真 N***（印证反信号①「384 是设计分位人为产物」）。
- c* = T/N* ≈ 1.07–1.14（N* 接近 T）——**支持「过拟合主犯 = c(n)→1 的极高频带」**
  （裁剪点越接近 T、剪掉 c≈1 的带越好）；491 波长（c=1.043）未进 64 维（T3），
  [480, 511] 内 N* 精确位置需 491 附近细扫（未来）。
- 与 3000 iters 对比：3000 下 N* ∈ [352,448] 宽区，27000 下 N* ∈ [448,480]——
  **N* 随训练轮数右移**（训练越深，过拟合带越窄、裁剪点越接近 T），
  进一步支持「c* 是变分平衡点（依赖训练量），非普适常数」（深度论侧证据增强）。

**论文 B 措辞**：§10.9a「与 4/3 的关系」段更新——27000 iters 聚焦扫显示 N* ∈ [448,480]
（5.15），**4/3 精确值假说被进一步否定**（384 为三点局部最优）；N* 随训练轮数右移
（3000: [352,448] → 27000: [448,480]）支持「裁剪点是设置函数」的深度论表述。
