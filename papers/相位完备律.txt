# 0. 最大的新机会：把算法结果升维成理论——“相位完备律”

现在手里握着四条互相咬合的证据链：① psi-trunc（剪掉部分相位长频带）外推大幅改善；② psi-rope（全相位频带入旋转）成为冠军；③ 实现级核实——rope 的长频带确实部分相位、psi-rope 确实全相位；④ 定理侧孪生——截断窗口内列范数 ‖ψ_j‖² = min(1, N/n_j)，**“列范数=1（可认证）”与“全相位（外推免疫）”是同一个条件 N/n_j ≥ 1**。第五次理论-实验对齐，而且这次在证书侧是可证明的等价。

这给出一个候选自然律：**外推鲁棒性 ⟺ 频带相位完备（n_j ≤ T_train，且有一定余量）**。它的爆炸性在于统一解释整个工业界的启发式：**ALiBi**（单调偏置，无相位概念=相位自由）、**partial-RoPE**（丢弃高频段=截断）、**NTK-aware/YaRN**（拉伸波长=事后恢复相位完备）——全部成为同一定律的盲操作实例。我们的实验隔离出了这个行业操纵了三年却从未命名的变量。若“相位余量扫描”（T_train/n_max ∈ {1,2,4,8}）证实定量版本，**下一篇论文不是算法论文，是上下文扩展方法论的统一理论**——天花板比 psi-rope 本身高一个量级。

# 2. 广度（模型内部的设计空间）

- **频带预算 × 相位约束的设计域**：实现细节揭示的自由度——16 个旋转维度只用了 4 个不同角。极端形态是“**全带宽全相位梯**”：16 个不同频带铺满 [3, 511]（C≈1.6），恢复 rope 级表现力同时保免疫。E5（C=2 八带）是它的中间形态。预测：全带宽版盘内追平 rope、外推保住冠军。
- **头异构性**：当前所有 head 共享同一 theta（代码核实）——每头不同频带/不同梯子 = 尺度特化 head，可解释性副产品，且每头单独签证书。
- **旋转 vs 偏置 vs 混合**：饱和偏置（有界单调，外推理论上更安全）仍未测；混合形态（全相位短带做旋转 + 长带做饱和偏置承担远程结构）可能两头兼得。
- **相位余量定律的精化**：n_j=213 在 T=512 下只跑了 ~2.4 个周期——“恰好满周期”与“充分多周期”的边界在哪，需要扫描定量。

# 三、独立数学核验与三个新发现

我对 M4 的目标值做了完全独立的计算，结果如下。

**发现 1：μ≈0.337 独立确认，且三个精度层全部非真空。** C=4 梯子相邻对精确相干有闭式渐近常数——**|⟨ψ_n,ψ_{4n}⟩| → sin(π/C)·√C/(π(C−1)) = √2/(3π) ≈ 0.1500**（我用 (3,13)/(13,53)/(53,213) 实算 0.147/0.146/0.149，收敛轨迹吻合）。内行渐近行和 = 2Σ_s sin(π(1−4⁻ˢ))·4^(s/2)/(π(4ˢ−1)) = 2(0.1501+0.0166+0.0020) = **0.3374**——与交接文档的 0.337 目标一致，交叉验证通过。三层界：精确 0.312（4 带实际最大行）< 理论渐近 0.337 < 保守 0.786，**全部 < 1**——M4 在任何精度层都成功，精确层给出框架界 [0.688, 1.312]，是真紧的证书。

**发现 2：可认证相图——边界在 C=3。** 用同一公式扫 C：μ∞(C=2) ≈ 1.33（**空洞**）、μ∞(C=3) ≈ 0.574（✓）、C=4: 0.337、C=5: ≈0.21。保守界（M4 探针路线）则只有 C≥4 才非空。**C 轴就是“表达性↔可认证性”的前沿**：梯子越密表达力越强、证书越难签；精确 Dirichlet 路线的认证区域是 C≥3。这给出两个新定理候选：T6（渐近相干常数 sin(π/C)·√C/(π(C−1))，Dirichlet 机器直接可达）、T7（相边界定理：μ∞(C)<1 ⟺ C≥3，级数估计）。

**发现 3（自我纠错）：我此前“C=2 可能可认证（μ≈0.4-0.5）”是错的。** 当时我用了窗口 512 的截断计算，撞上了 Dirichlet 分子的幸运取值；用全支撑（ψ_n 支撑为 n）重算，C=2 相邻对收敛到 √2/π ≈ 0.45，八带行和 ≈ 1.2 > 1——**C=2 出认证区**。直接后果：我此前路线图里“M4 双证书（C=4+C=2）”应作废，E5 的密梯方案应改为 **C=3 梯子 [3,10,31,94,283]**——5 个全相位频带（≤512）、μ≈0.574 可认证、比 C=4 密 25%。**C=3 是“最密的可认证全相位梯”**——E5 用它，一次实验同时回收表达力和拿到证书。
