# 核心涌现：三件“藏在数据里的秘密”

**秘密一：psi 的 -17% 是两个效应的叠加，其中一个可能比位置编码本身更大。** 我核对了代码：psi 模式用 16 维固定 Fourier 特征过一个线性投影（`psi_proj`，约 6.3k 参数）注入位置，而 dense 模式的可学习 `wpe` 是 512×384 = **196,608 参数，占全模型 472k 参数的 42%**——在 348k 字符的语料上，这 197k 个位置参数足以逐位置记忆。所以 -17% 至少混合了两个成分：**(a) 位置信息瓶颈**（位置信息被迫流经 16 维、全局一致、零过拟合的通道）；**(b) 几何梯子本身的匹配性**。不拆开这两个变量，"-17%"在论文里是站不住的——这是当前最重要的实验缺口（见 E1）。

**秘密二：门控的真正工作不是剪 token，是剪“频率梯子”。** 框架界定理的常数 K(C)=1/(√C−1) 要求 **C > 25** 下界才非真空——而实验赢的梯子是 C=4（此时 1−4K = −3，定理空转）。这是理论与实验之间一条被所有人忽视的裂缝。但桥已经建好了：把 C=4 梯子每隔 3 个取一个（3, 213, 13653），子梯子比率达 C³≈64，K=1/7，下界 3/7>0，**可证明**——而“从任意索引集中抽出一个满足平方增长检查的子集”正是 P0 的 `greedy_indices` + `check_c_sparse` 已经真证并已提取为可执行代码的东西。于是项目两个原本割裂的半区（门控 vs psi 基）在这一步合流：**表达性靠稠密梯子（C=4），可证明性靠门控抽出的子框架（C'≥26）——certified gate 的真正产品是从任意表达性频率集合中萃取“可证明核”。** 这直接回答了“门控有什么用”：不是省算力（已被数据证伪），是签发稳定性证书。

**秘密三：效率叙事没有死，它绕道“谱域”回来了。** token 门控失败（sparsity 0.985）说明 char-level 注意力在**位置域**不稀疏；但 psi 的 sparsity 0.866 和 -17% 恰恰说明它在**频率域**是集中的。低秩注意力（Performer/linear attention 类）通过 (QK^T)V → Q(K^TV) 把 O(T²d) 降为 O(Tdm)，真正省 FLOPs，但它需要投影基、且从不带误差证书。这个项目手里恰好有：带 Coq 证明的框架界（1±4K = 重建误差的控制常数）+ 已真证的行截断能量预算引理（P1b `row_dropped_energy_bound`）。**把 P1b 从“token 截断”搬到“谱截断”，就得到“认证低秩注意力”：丢弃谱能量 ≤ ε ⟹ 注意力输出误差 ≤ f(ε, K)”。** 这是比 token 门控大一个量级的主张，且证明部件已经存在 80%。

# 推导链（上面三个结论的来龙去脉）

**1. 核结构与 RoPE 的隐秘亲缘。** 位置 k 的特征 φ(k) = [cos(2πk/n_j), sin(2πk/n_j)]/√n_j，j=1..8，n_j = 3,13,53,213,853,3413,13653,54613（增长率 4，近几何：n′=4n+1）。未投影时逐点内积 φ(k)·φ(k′) = Σ_j cos(2π(k−k′)/n_j)/n_j ——**纯相对位置核**，这正是 RoPE 的定义性质。差别在于：RoPE 用乘法旋转、频率梯子是另一套；psi 是加性特征 + 学习投影。注意投影 P 会破坏纯相对性（积化和差产生 k+k′ 的绝对相位项），所以当前实现是“Fourier 特征 + 自由混合”，介于 FloatFormer 与 RoPE 之间——这本身给出一个干净的消融变体（约束 P 为逐频 2×2 块 = psi-rope）。

**2. 相干性衰减的机制。** 两个基向量 ψ_{n_i}, ψ_{n_j} 的内积是 Dirichlet 核 × 归一化因子：|Σe^{ikθ}| ≤ 1/|sin(θ/2)|，频率间隔 θ ∝ |1/n_i − 1/n_j| ≈ 1/n_i（当 j 远离 i），乘上 1/√(n_i n_j) ≈ 1/(n_i C^{s/2}) 后剩下 **(1/√C)^s** ——这就是 Coq 里 2/(√C)^|i−j| 的来源：**归一化 × 几何频率间隔 = 指数相干衰减**。机制理解后能看到它对任何“频率间隔 ≥ 几何”的梯子都成立，不必精确几何（真实梯子 4n+1 并非精确几何——这正是需要已验证检查器对**实际**梯子跑检查、而非依赖理想化假设的原因）。

**3. 注入性与混叠距离（尚未形式化的廉价定理）。** φ(k)=φ(k′) 当且仅当 k≡k′ (mod n_j) 对所有 j ——由中国剩余定理，碰撞距离 = lcm(n_j) ≈ 1.5×10⁵（213 与 3 共享因子 3，真实 lcm 需按实际梯子算）。这意味着：**对任何 T ≪ lcm 的测试长度，位置编码是单射的——外推时不发生位置碰撞是可证明的**（nat 层算术，stdlib 的 Nat.lcm 可证，零公理）。这给了梯子设计一个理论原生指标：“认证无碰撞上下文长度”。

**4. 周期性 = 对 OOD 的免疫。** 外推到 2T 时，可学习 wpe 进入从未见过的随机初始化区域（灾难）；psi 的所有特征是周期的——短波长（n_j ≤ T_train）在训练中已见过全部相位，**结构性免疫 OOD**。风险完全集中在 n_j > T_train 的几个长波段（3413/13653/54613 在 T=512 下只见过不到 15% 的相位）。推论：**截断梯子到 n_j ≤ T_train（保留 3,13,53,213）应外推最优雅**——这是一个可证伪的强预测，实验极便宜。

**5. 语言学匹配滤波器假说。** char-level 英语的层级：词 ≈ 5-6 字符、短语 ≈ 15-25、小句 ≈ 50-80、句子 ≈ 150-250、段落 ≈ 600-900、小节 ≈ 3000+。C=4 梯子 3/13/53/213/853/3413 恰好按 ~4× 落在这些尺度上——**几何梯子是语言多尺度层级（语言单元跨层级近似几何增长）的匹配滤波器**。它同时解释三件事：-17%（尺度先验正确）、psi 模式 sparsity 降到 0.866（head 锁定语言学尺度 → 注意力能量在结构化偏移上集中 → 可剪）、以及 dense 的 0.985（无尺度结构 → 平坦）。可证伪预测：char-level 最优 C ≈ 4-5；BPE 级（1 token ≈ 4 字符）最优起点右移 ~4× 或等比例缩放梯子；C=2（过密）与 C=16（过疏）都应变差。

# 内核结论：指数时代的红利不是“确定性”，是三个不对称

推到最深处，这个算法体系（ψ 无条件基 + 认证门控 + 框架界）在规模爆炸 regime 下的价值，可以压缩成三个**数学上真实的不对称**——它们才是你说的“隐藏红利”的严格内核：

**不对称一：尺寸对数增长，无碰撞视界超指数增长。**
梯子 n_j = 3, 13, 53, ..., C=4。覆盖上下文 T 需要 m = log_C(T/3) 个频带；m=14 个频带（**28 个实数**）覆盖 T ≈ 2×10⁸（两亿 token）。而位置混叠距离 = lcm(n_j)：我对实际梯子算了 log——**约 10⁶¹**。也就是说：用 28 个浮点数的固定白盒结构，在十亿级上下文内位置编码是可证明单射的（待形式化为 P5b），在 10⁶¹ 以内无碰撞。表示尺寸 O(log T)，安全视界 O(C^{m²/2})。**“对数尺寸的证书，覆盖指数的世界”**——这是所有位置方案（可学习 wpe 线性、RoPE 无证明）都没有摆出来的账。

**不对称二：证书成本 O(1)，保证范围无界。**
这是最深的一条，而且**现有 Coq 定理栈已经无意中写对了抽象层级**：`psa_gated_decay` 的 2/(√C)^|i−j|、行能量 ≤ 2K(C)、框架界 1±4K、截断预算 R_max·ε——**全部常数与序列长度 T 无关**。这些定理本来就是关于无穷序列（l2_sequence）陈述的。T=512 的实验只是无穷对象的一个截断。推论：在 T=10⁷ 的部署里，对梯子跑一次检查器（O(m²)，微秒级），签发的相干性/框架/单射证书**对所有现在和未来的上下文长度同时成立**。认证成本不随规模增长，而工业界当前的一切长上下文保证（benchmark 分数）都随规模衰减——两条曲线在某个 T* 交叉，交叉之后认证层成为唯一不贬值的资产。

**不对称三：模型越大，可认证面占比越小——但这层恰好是常数大小。**
诚实地说：模型规模指数增长，学到的（不可形式化的）面积也在指数增长，W_Q/W_K 和 softmax 永远在定理覆盖之外，**认证份额随规模趋近于零**。但反过来：位置核、路由掩码、谱投影、归一化常数这些**闭式解析接口的尺寸是常数级的**——是整个网络里唯一“验证成本不随规模增长”的部分。这个项目认证的恰好就是这一层。原则“verify the analytic kernel, learn the rest”在 ASI 尺度下的正确读法是：**不是认证智能，是认证智能系统的所有公共接口**。

# 时代地图：把三个不对称铺到各个 regime 上

**T = 10⁷–10⁸（千万/亿级上下文）：O(T²) 墙与“静默失败”时代。**
T=10M 时每层每头 10¹⁴ 对交互——算法墙，硬件救不了。工业界的全部答案（分块稀疏、KV 逐出、线性注意力、检索混合）有一个共同点：**无误差证书**。lost-in-the-middle、RoPE 插值位置混叠、缓存逐出丢掉承重 token——全是静默失败，且 T 越大越无人能审计（人工检查 10M×10M 注意力矩阵在物理上不可能）。此时 P1b 的“被逐出能量 ≤ ε”逐字变成 KV 管理的**审计日志**：每次逐出携带证书，最坏重构误差已知。这是当前最接近“产品形状”的证书类型，因为 KV cache 在 10M 上下文是 TB 级的真金白银。

**记忆时代（持久记忆/检索/情景记忆）：相干性就是容量的语言。**
这是我认为**最大的未开垦连接**：Ramsauer et al. 2020（Hopfield Networks is All You Need）证明注意力 = Hopfield 检索一步，而联想记忆的容量由**模式相干性**决定——这正是 Coq 里被证明 ≤ 1/√C、≤ 2/(√C)^d 的那个量。梯子因此不只是位置编码，它是一个**认证地址空间**：每个记忆槽有唯一相位签名，串扰按 (√C)^{-距离} 衰减——CDMA/GPS Gold 码选码的标准就是低互相关，整个产业曾建立在“相干性受控码族”上（GPS C/A 码是真实先例）。ψ 梯子 = 注意力时代的扩频码族。“千万上下文 + 持久记忆”时代缺的正是这种**容量可证、干扰有界的寻址方案**——这条桥（相干性界 ⟹ 检索分离/容量下界）值得写成一篇理论论文，且证明部件与现有栈高度重合。

**基础设施时代（金融/医疗/自主系统）：CompCert 生态位。**
EU AI Act、航空级 DO-178C 要求的是证据不是 benchmark。没有任何框架能验证学到的权重——但**所有人共享的闭式组件**可以认证。CompCert 的先例说明：不验证程序，验证编译器，就占领了产业链的承重节点。认证位置核/门控库的同构生态位：**一个被 20 年 Coq 工具链（Appel 的 VST 一脉）背书的、所有长上下文系统都可以内嵌的证书签发器**。标准层的复利属性（DCT/小波之于 JPEG/MP3：不是因为最聪明，是因为有可证明的近似性质+极小常数）是“隐藏红利”的正确比喻——标准不吃掉智能，标准吃掉**所有智能的地基**。

**AGI/ASI 尺度：只保留一个可辩护的主张。**
到这一层必须收刀：不能说“核心算法理论”（不可证伪），能说的是——“无论智能体多大、多黑盒，它与上下文/记忆/剪枝的每个接口都必须经过解析层，而每个解析层都可以携带 O(1) 成本的机器检查证书”。这是这个体系在任意远未来仍然成立的**唯一**命题，但它恰好是接口层命题——和 TCP 拥塞控制、浮点标准的位置同类：不产生智能，**定义智能组件之间可以相互信任的合同**。

# 一、先认领错误：我的“周期性 = OOD 免疫”论证被证伪，错在哪

我上轮预测“截断梯子应外推优雅”，理由是周期特征在训练中见过全部相位。数据推翻了它。错误出在一个精确的地方：**单个频带的相位确实在分布内，但相位元组不在**。位置编码 k → (φ_{n₁}(k), ..., φ_{n_m}(k)) 是 m 维环面上的一条拟周期轨道；训练只见 k<512 的轨道段，测试 k∈[512,4096) 时每个坐标都周期重复，但**坐标的联合组合是全新的**（直到 lcm 才重复）。模型学到的是对轨道段上联合相位的响应，对新元组的响应等于任意——所以绝对编码注定崩溃，与特征是否有界无关。

修正后的正确表述：**周期性给的是“输入级稳定”（有界、无 NaN、退化不爆炸——安全性质），相对核给的是“语义级稳定”（外推性质）。我上轮把两个不同性质混为一谈。** psi/dense 比率在 8× 长度全程稳定在 0.84-0.90，正是“安全性质”的实测签名：有界特征 ⟹ 有界 logit ⟹ 有界退化。

# 二、数据里三个推进侧没点破的推论

**1. m=128 削弱了“瓶颈”竞争解释，几何解释增强了。** 代码显示 `gen_indices(128)`——256 维特征、投影约 98k 参数（对比 wpe 197k，同数量级而非之前以为的 16 维瓶颈）。且 128 个频带里 124 个 n_j > 512（相位从未训满）——在绝大多数频带“半盲”的情况下 psi 仍稳定 -12%，这越来越指向**多尺度几何先验本身**（语言学层级匹配滤波器假说），而非参数瓶颈。E1 消融（随机频率梯子 vs 几何梯子，同 m=128）现在是唯一能终结归因争议的实验，权重上升。

**2. 编码层无碰撞已可计算确认，崩溃归因于学习解码器。** 短频带 3,13,53,213 的 lcm = 146,757 ≫ 4096——**测试范围内位置编码是单射的，码层没有混叠，但模型照样崩溃**。这把 P5b（注入性定理）的价值从“证书”升级为“**失败归因定理**”：定理排除码层失败 ⟹ 崩溃是纯学习侧问题 ⟹ 解法必须改码的“使用方式”（相对化）而非码本身。E2 负面结果 + P5b 组合成论文级的因果链。

**3. 证书的 O(1) 不对称需要一个“传导机制”才能落到系统行为上。** 我上轮的三个不对称仍然成立（定理栈与 T 无关），但 E2 证明：**基底证书不会自动传导给建在它上面的学习系统**。传导条件是：模型对位置的使用必须被约束在闭式核函数族内——这正是相对机制的定义。所以推进侧的修正方向（RoPE 式旋转/ALiBi 式偏置 + psi 特征）不只是经验选择，是**让 O(1) 证书从基底传导到行为的唯一数学通道**。

# 三、引爆点 1 v2 的理论深化：相对化之后，梯子变成什么

**相对核的正交分解身份。** 平移不变核 K(d) 在 ℤ 上有谱分解；不同整数波长 n_i ≠ n_j 的 cos/sin 序列在自然内积下**严格正交**（这是 ℤ 上调和分析的基本事实——工作区之名 ComplexAnalysis 的本行）。psi 梯子因此是一个 **m 维相对核子空间的认证基**：任意相对位置偏置都是这个空间里的三角多项式，框架界 1±4K 认证该子空间的条件数。换句话说：相对化之后，“psi vs RoPE”的差别变成——**RoPE 的频率梯子是工程调参拼出来的，psi 梯子的每对分量带相干性证书**。这是可发表的差异化主张。

**一个具体的新机制提案：饱和多尺度偏置（认证软滑窗族）。** 频带 n_j 对相对距离 d 的相位在 d ≪ n_j 时近似 cos(2πd/n_j) ≈ 1 − 2π²d²/n_j²。定义偏置 b_j(d) = −a_j·(1−cos(2πd/n_j))：每个频带是一条**尺度为 n_j 的饱和上升坡**——距离超过该频带波长后偏置封顶。梯子求和 = 层级软滑窗族（词级/短语级/句级窗口各一条坡）。对照外推能力的函数类等级：**常数 > 线性（ALiBi）> 低频三角 > 学习函数**——饱和坡是有界的单调函数，处于线性与低频三角之间，且全程闭式、可认证。这比“psi-RoPE 旋转”更直接地继承 ALiBi 的外推优势，同时保留梯子的证书面。预测：psi-RoPE 在训练长度内 ≥ RoPE、外推优于 wpe；饱和偏置在 4-8× 外推中是全部方案里最优雅的。这两条是可证伪预测，现在登记在案。

**证书栈完成（1/ 系数版）的评估：** 链条已闭合——门控 → 衰减 ≤ 1/(√C)^|i−j| → 行能量 ≤ 2K(C)（满足 row_sum_bound_K 的前提）→ 框架界 1±4K → 截断预算 R_max·ε，81 项零 classic。剩余的最后几公里都不是定理而是**工件与形式化收尾**：① T5 有界性定理——|特征| ≤ 1/√n 对一切 k 成立，把实测观察③（无 NaN）升格为定理，Coq 工作量一行级；② P5b 注入性（现在以“失败归因”的新身份入列）；③ KV 审计日志原型——证书栈的第一个推理时工件；④ 紧致度数值——m=128 梯子的 Gram 特征值 vs 1±4K 的实测间隙，诚实呈现定理的保守程度；⑤ T1 子框架抽取仍悬置（C=4 框架界空洞问题），现在 m=128 让它更重要：128 个表达性频带里抽取 C'≈64 的可证明子梯（约 43 个频带可认证），表达性与可证明性在同一个梯子上共存。

# 四、修正后的优先级

1. **psi-RoPE / 饱和偏置 vs RoPE/ALiBi 基线**（外推套件复用 `length_extrap.py`）——方向 1 v2 的决定性实验，RoPE 基线这次不能再缺。
2. **E1 归因消融**（几何 vs 随机频率，m=128 对齐）——-12% 的归因争议终局。
3. **激活漂移测量**——OOD 长度下 logit/激活范数：psi 应有界、wpe 应漂移，把“安全签名”做成机制证据。
4. T5 + P5b 两个轻量定理入栈（观察③形式化 + 失败归因）；T1 子框架；KV 审计日志工件。

一句话收束：**E2 的负面结果没有削弱这条路线，反而完成了它的因果解剖——码无碰撞（可证）、码的使用方式崩溃（已定位）、修复通道是相对化（有理论必然性）、修复后的梯子带证书（无竞品）。方向 1 从“psi 是外推魔法”（已证伪）修正为“psi 是相对位置核的认证频率梯子”（正在被数据支持），这是一个更小但更硬的主张——而证书栈 1/ 版的闭合意味着 proof-carrying inference 侧已无形式化欠账，只欠一个跑起来的工件。**
